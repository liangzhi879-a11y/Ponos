## 输出资料合规规则（禁止AI生成水印）

> **核心原则**：所有输出给客户的资料**禁止包含任何AI生成水印**。
> 资料是企业正式申报文件，必须看起来像人工撰写的专业文档。

### ⚠️ 交付前强制检测（v2026-07-28 新增）

**所有提交资料在最终交付前，必须运行 AI 水印检测，检测通过方可交付。**

```
交付前检测流程：
  步骤1：python validate_submission.py --output-dir "_最终申报包/"
  步骤2：查看报告中的 ai_watermark_hits 字段
  步骤3：ai_watermark_hits > 0 → 🚫 停止交付，逐一清除水印后重新打包
         ai_watermark_hits = 0 → ✓ 通过，可交付
```

**触发条件**：以下任一操作完成后立即触发
- `submission_packager.py pack` 打包完成
- 任何技能产出最终交付文件
- 用户说"提交资料/交付/上传系统"等关键词

**自动检测规则**（已内置在 `validate_submission.py` 第7维）：
| 检测类别 | 正则匹配 |
|---------|---------|
| AI生成声明 | `AI生成` `AI辅助` `AI撰写` `AI创作` `AI编写` |
| 自动生成声明 | `自动生成` `由xxx脚本生成` `由xxx程序生成` |
| 模型标识 | `Generated by` `Powered by` `Created by` + AI/Claude/GPT/TRAE/Copilot/DeepSeek |
| 工具水印 | `TRAE` `Claude` `ChatGPT` `GPT-4` `OpenAI` `大语言模型` `LLM` |
| AI水印文字 | `AI watermark` `AI水印` `AI标识` `模型生成` |

### 禁止的水印形式

| ❌ 禁止内容 | 示例 |
|-----------|------|
| 脚本署名行 | `*本报告由 xxx.py 自动生成*` |
| AI工具署名 | `*本报告由 AI 辅助生成*` |
| 模型标识 | `Powered by TRAE` / `Generated by Claude` |
| 生成声明 | `*本材料由 AI 工具辅助撰写*` |

### 允许的元数据（非水印）

| ✓ 允许内容 | 说明 |
|-----------|------|
| 生成时间戳 | `**生成时间**：2026-07-18 10:30:00` |
| 企业名称 | `**企业名称**：xxx科技有限公司` |
| 文档版本 | `**版本**：v1.0` |
| 编号字段 | `报告编号：RPT-2026-001` |

### 涉及的输出资料类型

核对报告、校验报告、提取结果、匹配报告、核心表格、证明材料、OCR结果 — 全部必须无AI水印。

### 文档版本管理规则

1. 规定目录仅保留最新版本，旧版本以 `.bak` 备份
2. 备份文件夹：`.trae/output_backup/{skill_name}/`

```bash
# 产出新文档前备份旧版本
python output_version_manager.py backup --path <output_path> --skill <skill_name>
# 清理过程版本文件
python output_version_manager.py cleanup --dir <dir> --skill <skill_name>
```
