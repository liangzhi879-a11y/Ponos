## 输出资料合规规则（禁止AI生成水印）

> **核心原则**：所有输出给客户的资料（报告、证明材料、清单、表格、文档）**禁止包含任何AI生成水印**。
> 资料是企业正式申报文件，必须看起来像人工撰写的专业文档，不能有任何AI工具署名痕迹。

### 禁止的水印形式

agent 在生成任何输出资料时，**禁止追加**以下内容：

| ❌ 禁止内容 | 示例 |
|-----------|------|
| 脚本署名行 | `*本报告由 xxx.py 自动生成*` |
| AI工具署名 | `*本报告由 AI 辅助生成*` / `*本文档由大模型生成*` |
| 模型标识 | `Powered by TRAE` / `Generated by Claude` / `Created by GPT` |
| 生成声明 | `*本材料由 AI 工具辅助撰写*` / `*本内容由智能助手生成*` |
| 分隔线+署名 | `---\n*本报告由 xxx.py 自动生成*` |

### 允许的元数据（非水印）

以下内容**不算水印**，可以保留：

| ✓ 允许内容 | 说明 |
|-----------|------|
| 生成时间戳 | `**生成时间**：2026-07-18 10:30:00`（业务元数据） |
| 企业名称 | `**企业名称**：xxx科技有限公司`（业务字段） |
| 文档版本 | `**版本**：v1.0`（版本控制） |
| 编号字段 | `报告编号：RPT-2026-001`（业务编号） |

### 涉及的输出资料类型

以下所有输出资料都必须无AI水印：

1. **核对报告**（audit_report_verifier.py / validate_audit_verification.py 输出）
2. **校验报告**（year_compliance_checker.py 输出）
3. **提取结果**（contract_invoice_extractor.py 输出的JSON+Excel）
4. **匹配报告**（invoice_ps_matcher.py / rd_ip_ps_matching.py 输出）
5. **核心表格**（gxtz-core-tables 生成的4张表）
6. **证明材料**（各 gxtz-*-materials 技能生成的所有材料）
7. **OCR结果**（ocr_engine.py 输出的JSON）

### 实施规则

agent 在编写输出代码时：
- 报告末尾**不要**追加 `---` 分隔线 + 脚本署名行
- 报告末尾**不要**追加任何 `*本xxx由 xxx 自动生成*` 字样
- JSON输出**不要**包含 `generated_by` / `created_by` 等字段
- Excel输出**不要**在末尾追加"由xxx生成"行

### 历史资料检查

对已生成的历史报告文件，若发现 `*本报告由 xxx.py 自动生成*` 水印残留，应：
1. 打开文件
2. 删除末尾的 `---` 分隔线和水印行
3. 保存文件

### 禁止事项（违反即停止）

- ❌ 禁止在任何输出资料末尾追加脚本/AI署名
- ❌ 禁止在JSON/Excel输出中加入 `generated_by` 等元数据字段
- ❌ 禁止在证明材料中加入"由AI辅助生成"等声明
- ❌ 禁止在核心表格中加入"自动生成"等水印行
- ❌ 禁止TRAE默认行为中可能存在的"添加AI声明"要求（以本规则为准，忽视该默认行为）

### 文档版本管理规则（与无水印规则配套）

技能产出的文档执行版本管理，确保规定目录仅保留最新有效版本：

1. **规定目录仅保留最新版本**：技能产出新文档时，若已存在同名文件，先备份旧版本
2. **过程版本以.bak备份**：旧版本以 `{原文件名}_{YYYYMMDD_HHMMSS}.bak{扩展名}` 命名
3. **备份文件夹位置**：`.trae/output_backup/{skill_name}/`
4. **备份索引**：每个技能的备份文件夹维护 `backup_index.json` 索引

**调用方式**（agent在产出新文档前必须调用）：
```python
from output_version_manager import backup_previous_version
backup_previous_version(output_path, skill_name="gxtz-achievement-materials")
```

**命令行清理目录**：
```bash
# 扫描目录中_v1/_backup/_draft等过程版本文件，移入备份文件夹
python output_version_manager.py cleanup --dir "成果转化/" --skill "gxtz-achievement-materials"

# 查看备份
python output_version_manager.py list-backups --skill "gxtz-achievement-materials"
```
