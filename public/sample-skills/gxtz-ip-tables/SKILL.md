## 角色定位

本技能负责高新技术企业认定中**IP知识产权表**的生成与模板注入。数据来源于企业提供的专利/软著证书扫描件。

## 输出文件

- `{企业名称}-知识产权表（参与本次创新能力知识产权评价，汇总信息只统计此列表中的知识产权）.xlsx`
- 存放到 `00_核心表格/` 目录

## 核心脚本

```bash
# 生成IP表
python {{PONOS_SKILLS}}/_common/generate_ip_table.py --project-root "."
# 校验IP表
python {{PONOS_SKILLS}}/_common/validate_ip_table.py --input "00_核心表格/IP表.xlsx"
```

或者使用模板注入方式（**强制使用**）：

```python
from _common.template_injector import TemplateInjector

injector = TemplateInjector(template_dir="00_核心表格", output_dir="_output", enterprise_name="企业名")
injector.inject_ip_table(ip_data)
```

### 字段提取方法

```python
def extract_ip_fields(ip_info):
    """
    从知识产权信息中提取字段
    ip_info: dict，包含知识产权基本信息
    """
    ip_data = {
        '知识产权编号': ip_info['ip_id'],
        '知识产权名称': ip_info['name'],
        '类别': ip_info['category'],
        '获得方式': ip_info['acquisition_method'],
        '专利号/著作权号': ip_info['patent_number'],
        '授权日期': ip_info['authorization_date'],
        '知识产权所属单位或个人': ip_info['owner'],
        '国家知识产权局官方网站上公布的摘要(限400字，软件著作权不用提供)': 
            '无' if ip_info.get('category') == '软件著作权' else ip_info.get('abstract', ''),
        '与本知识产权相关的核心关键技术先进性说明(限400字)': ip_info['advancement'],
        '该知识产权与本企业产品（服务）核心技术的支持作用说明(限400字)': ip_info['support_role'],
    }
    return ip_data
```

## 撰写步骤

1. 填写知识产权编号、名称、类别、获得方式
2. 填写专利号/著作权号、授权日期、所属单位
3. **填写摘要**：严格根据专利说明书原文摘录（从国家知识产权局官网公布的专利说明书中提取，不限制字数，保留原文表述）；**软件著作权摘要必须填"无"（禁止空值）**
4. 填写先进性说明（限400字）、支持作用说明（限400字）
5. 验证所有IP编号唯一性
6. **字数校验**：先进性说明、支持作用说明字数 >= 300字（摘要字段不校验字数）

## 长文本字段生成规范（v1.39.0核心变更）

IP表的2个长文本字段必须由 agent 按提示词逐IP生成，**禁止算法拼接或模板句填充**。

### 生成流程

```
对于每个 IP:
  Phase 1: 构建上下文包
    -> IP名称 + IP摘要原文 + IP类型 + 关联RD名称 + 关联RD技术方向 + 关联PS名称

  Phase 2: agent 按以下要求生成先进性说明（300-400字）
    -> 结合 IP 的技术创新点与关联 RD 的研发方向，说明该 IP 在行业内的技术先进程度
    -> 不出现编号（RD01/IP01），不出现夸大词（领先/首创）
    -> 语言正式，采用概括性表述

  Phase 3: agent 按以下要求生成支持作用说明（300-400字）
    -> 说明该 IP 如何支撑关联 PS 产品的核心技术
    -> 明确 IP 对产品性能/功能/质量的具体支撑关系
    -> 不出现编号，不出现夸大词

  Phase 4: 质量门禁
    -> 字数检查（>=300字）/ 编号泄露检查 / 夸大词检查
    -> 不合格自动重跑（最多2次）

  Phase 5: 脚本注入
    -> template_injector.inject_ip_table() 将生成内容注入模板
```

### 禁止事项

- **禁止 `optimize_text_to_fit()` 截断**：不得对 IP 摘要/先进性说明/支持作用说明执行自动截断
- **禁止算法拼接**：不得从 IP 摘要中提取关键词拼接为"先进性说明"
- **禁止 fallback 模板句**：不得使用"该技术具有较高的先进性，对产品有重要支撑作用"等通用模板句
- **禁止批量算法生成**：每份 IP 的长文本必须独立生成，不得用循环 + 变量替换模式批量产出

## 时间约束

```
IP授权日期 <= 申报年份（申报前必须已授权）
IP授权日期无下限（旧专利也可使用）
但建议IP授权日期集中在近三年内，以体现创新能力
```

## 摘要特殊规则（v1.18.2）

- 知识产权摘要（第8列）**不校验字数下限**，严格根据专利说明书原文摘录
- 字数长短由专利说明书本身决定，可短可长
- **软件著作权摘要必须填"无"（禁止空值，禁止填其他内容）**

## 审核校验

### 字数校验
- 先进性说明（>=300字，<=400字）
- 支持作用说明（>=300字，<=400字）
- 摘要：不校验字数（严格按专利说明书）

### 字段命名校验
- 禁止使用"编号"代替"知识产权编号"
- 禁止使用"授权号"代替"专利号/著作权号"（根据模板）

### 生成前自检清单

```
[ ] IP表列名从第1列到第10列逐一核对，无简化无合并
[ ] 类别下拉值正确（发明专利分为国防/非国防两个选项）
[ ] 获得方式下拉值正确
[ ] 列序与模板完全一致
[ ] 所有IP编号唯一
[ ] 软著摘要填"无"
```
