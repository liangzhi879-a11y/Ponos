## 合规红线（agent 执行前必读，违反即停止）

> **第一要求：严谨合规。所有数据必须真实可溯源，禁止任何形式的编造。**

### 禁止事项（违反任何一条立即停止并告警）

1. **禁止仅靠文件名分类**：必须读取文件内容（PDF文本/DOCX全文/XLSX表头/图片OCR）进行内容级判断，文件名仅作辅助线索
2. **禁止跳过内容识别步骤**：每个文件必须经过内容识别分类器处理，不得跳过直接按文件名归类
3. **禁止移动原始文件**：模块B（申报材料）和模块C（备案资料）为**复制**模式，不得移动原始文件
4. **禁止跳过脚本执行**：所有 `python {{YFW_SKILLS}}/_common/xxx.py` 命令必须通过 Bash 真正执行
5. **禁止跳过审核步骤**：审核验证步骤必须执行且通过，未通过时不得继续后续步骤
6. **禁止自行兜底**：脚本报错时不得自行编写兜底代码，必须停止并告警由用户决定
7. **禁止跨技能污染**：仅读取当前项目留痕，不跨项目读取

### 数据来源优先级（高 → 低）

- **官方文档**（所得税申报表 > 申请书 > 证书）：✅ 可直接采用
- **内容识别结果**（file_content_classifier.py 输出）：✅ 作为分类依据
- **项目推断**（从文件内容关键词推断）：⚠️ 置信度<70%时需人工确认
- **缺失**：❌ 不得编造，必须标注"待补充"

### 无法确认时的处理

- **内容识别置信度 < 70%**：标记为"需人工确认"，列出候选类别，不强行归类
- **脚本报错**：立即停止，输出错误日志，由用户决定修复方案
- **审核不通过**：停止后续步骤，输出 ERROR 清单，由用户决定整改方案

## 描述

本技能对高新技术企业认定项目的原始资料进行全流程整理，是执行其他gxtz-*技能之前的**前置技能**（阶段0）。

核心功能：
1. **原始资料整理** — 递归解压所有压缩包→读取文件内容识别材料类型→按时间有效性筛选(保留近三年)→按19类归入对应目录→过期资料单独归档
2. **申报材料整理** — 参照深圳市高新申报系统19项材料清单(资料要求.xlsx)→内容级匹配→按规范重命名(如IP01_专利名称.pdf)→大小合规校验
3. **备案资料整理** — 参照完整备案模板(00高新模板（全）)→扫描模板结构→内容级映射→生成缺失清单
4. **备份资料** — 识别迭代旧版本/重复文件→.bak处理→统一归集到备份文件夹

**核心原则**：所有分类判断基于**打透文件内容**（非文件名），低置信度标记人工确认。

## 输入输出

- **输入**：
  - 企业项目根目录（包含客户原始资料的文件夹，如 `D:\OneDrive\文档\工作\【国高】20260622 深圳派成铝业科技有限公司`）
  - 资料要求.xlsx（深圳高新申报系统19项材料清单，位于本技能项目目录 `c:\Users\T203-15\Desktop\2023guogao\资料要求.xlsx`）
  - 00 高新模板（全）（完整备案资料集模板，位于 `c:\Users\T203-15\Desktop\2023guogao\00 高新模板（全）`）
- **输出**：
  - `{项目根目录}/000 原始资料/` — 按19类目录整理的原始资料（含过期资料归档）
  - `{项目根目录}/000 申报材料/` — 按19项材料清单命名排列的申报材料（含命名对照表）
  - `{项目根目录}/000 备案资料/` — 按模板结构组织的备案资料（含缺失清单）
  - `{项目根目录}/_备份资料/` — 统一备份文件夹（含备份索引）
  - 整理报告、命名对照表、缺失清单、备份索引
