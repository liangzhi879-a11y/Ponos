## 合规红线（agent 执行前必读，违反即停止）

> **第一要求：严谨合规。所有资质数据必须来自官方政策原文，评分必须逐项可追溯，禁止编造任何申报条件。**

> ⚠️ **政策原文为准**：独角兽（多为地方/机构榜单认定）与制造业单项冠军（工信部认定）评定口径不同且逐年调整。本技能内置条件为政策框架基准，**一切条件、榜单口径、材料要求必须与当年度官方通知/榜单发布机构规则核对后采用**，并记录出处。

### 禁止事项（违反任何一条立即停止并告警）

1. **禁止编造申报条件**：估值门槛、市占率排名、深耕年限等条件不得凭记忆或推断填写，必须与当年度官方通知/发布机构规则核对
2. **禁止编造企业估值**：独角兽估值必须基于**可查证的最新一轮融资**（投资协议/融资公告/权威媒体披露/榜单机构数据），禁止自行估值或估算
3. **禁止编造市场地位**：全球市场占有率前三的判定，必须有权威第三方来源（国际行业协会/国际咨询机构报告/海关出口统计/上市公司公告），**禁止以客户估算或AI推算作为依据**
4. **禁止推断关键数据**：营收、市场占有率、深耕年限等字段必须以审计报告、行业报告、成立注册文件等为准
5. **禁止跳过脚本执行**：所有 `python C:/Users/T203-15/.ponos/skills/_common/xxx.py` 命令必须通过 Bash 真正执行，不得"阅读脚本逻辑自行编写等效代码"
6. **禁止跳过审核步骤**：审核验证步骤必须执行且通过，未通过时不得继续后续步骤
7. **禁止自行兜底**：脚本报错时不得自行编写兜底代码，必须停止并告警由用户决定
8. **禁止跨技能污染**：仅读取当前项目留痕，不跨项目读取

### 数据来源优先级（高 → 低）

- **官方文件**（工信部通知原文/审计报告/注册登记文件）：✅ 可直接采用
- **权威第三方**（国际咨询机构/行业协会/投行研报/融资公告/知名榜单机构）：⚠️ 需标注机构名称、报告日期、统计口径后采用
- **媒体披露**（权威财经媒体报道）：⚠️ 需交叉验证后采用
- **缺失**：❌ 不得编造，必须标注"待补充"

### 无法确认时的处理

- **估值无法查证**：暂停独角兽方向，提示用户提供投资协议或融资公告，禁止估算
- **全球排名数据缺失**：暂停单项冠军方向，提示用户提供国际咨询机构/行业协会报告
- **当年度官方通知未检索到**：停止申报流程，提示用户检索官方原文
- **脚本报错**：立即停止，输出错误日志，由用户决定修复方案
- **审核不通过**：停止后续步骤，输出 ERROR 清单，由用户决定整改方案

## 执行顺序契约（agent 必须严格遵守）

### 执行原则

1. **顺序执行**：必须按第一步 → 第二步 → ... → 最后一步顺序执行，严禁跳过任何步骤
2. **失败即停**：任何步骤失败（脚本报错、校验不通过、数据缺失）立即停止，输出错误信息，不得继续
3. **不可并行（有依赖时）**：技能内步骤有数据依赖时不得并行；跨技能独立任务在蜂群编排下可并行执行，参见蜂群编排规范（_swarm_orchestration.md）
4. **不可跳过审核**：审核验证步骤必须执行且通过，未通过时不得进入下一步

### 步骤编号规则

- **第一步**：项目初始化（强制执行，不可跳过）
- **第二步 ~ 倒数第二步**：核心业务步骤
- **最后一步**：审核验证（必须通过才能提交）

### 失败处理标准流程

1. **立即停止**当前步骤及后续所有步骤
2. **输出错误信息**：包含失败步骤、错误原因、脚本日志（如有）
3. **输出已完成的步骤清单**：让用户了解当前进度
4. **等待用户决定**：由用户决定修复方案（核对政策原文/补充资料/手工处理）
5. **禁止自行兜底**：不得"阅读脚本逻辑自行编写等效代码"

## 工作流

### 第一步：项目初始化（强制执行，不可跳过）

```bash
python C:/Users/T203-15/.ponos/skills/_common/project_context_manager.py init --enterprise "{企业名称}" --year {申报年份}
```

初始化后读取 file_map.json（文件分布）与 experience_base.json（历史经验）。

### 第二步：估值/市场地位评估（二选一方向判定）

**独角兽方向**：
1. 收集最新一轮融资材料（投资协议/融资公告/权威媒体披露/榜单机构数据）
2. 估值≥10亿美元 → 记录估值依据与来源；不足 → 输出差距与建议（不编造估值）
3. 核对成立年限、上市状态等辅助条件
4. 输出《估值评估表》：估值 → 轮次 → 投资方 → 数据来源 → 达标状态

**单项冠军方向**：
1. 收集全球市场占有率数据（国际咨询机构/行业协会/海关出口统计/上市公司公告）
2. 核实细分产品全球排名前三的判定，标注统计口径与报告日期
3. 核对深耕年限（≥10年）与细分领域界定
4. 输出《市场地位评估表》：细分市场 → 全球排名 → 数据来源 → 达标状态

### 第三步：行业排名数据收集

1. 界定细分市场（产品品类+全球范围+统计口径，尽量对齐权威机构口径）
2. 收集全球竞争格局：头部企业名单、各家营收/份额、市场容量与增速
3. 多来源数据冲突 → 暂停确认（A类），由用户指定以哪个来源为准
4. 输出《行业排名数据包》：数据表 + 全部来源报告原件 + 口径说明

### 第四步：技术积累叙事构建

1. 梳理企业成立以来的技术演进脉络（关键里程碑/首台套/技术迭代节点）
2. 挖掘长期深耕证据：历年研发项目、专利时间线、标准参与、客户长期合作
3. 撰写《长期技术积累叙事》：深耕年限 → 技术演进 → 行业地位形成逻辑
4. **叙事必须事实可查证**，禁止"填补国内空白"等无据表述

### 第五步：申报材料准备

- **复用部分（约40%）**：IP证书（gxtz-ip-materials）、技术资料（gxtz-rd-report）、财务数据（gxtz-core-tables TOAI表）
- **新增部分（约60%）**：估值/市场地位佐证、行业排名数据包、融资记录/国际客户证明、深耕年限证据链（历年认证/荣誉/里程碑）
- 输出《材料清单》：每项标注"复用来源 / 新增需提供"

### 最终步：审核验证（必须通过才能提交）

1. **条件审核**：估值或全球排名达标，深耕年限/领域界定符合通知要求
2. **真实性审核**：估值有融资文件佐证；全球排名有权威第三方报告佐证；技术叙事全部事实可查证
3. **一致性审核**：申报数据与审计报告、行业报告一致
4. **政策原文审核**：所有条件与当年度官方通知/发布机构规则逐条核对一致
5. **文件审核**：调用命名规范检测（naming_compliance.py），PDF格式与大小合规
6. 生成《独角兽/单项冠军申报审核报告》，输出 ERROR 清单或审核通过结论
