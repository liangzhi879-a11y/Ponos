## 合规红线（agent 执行前必读，违反即停止）

> **第一要求：严谨合规。所有资质数据必须来自官方政策原文，评分必须逐项可追溯，禁止编造任何申报条件。**

> ⚠️ **政策原文为准**：小巨人评审为国家级，申报条件（营收/研发/IP/市占率）逐年可能调整，且存在"直通/简化程序"等特殊通道。本技能内置条件为政策框架基准，**一切条件与材料要求必须与工信部当年度通知原文核对后采用**，并记录出处。

### 禁止事项（违反任何一条立即停止并告警）

1. **禁止编造申报条件**：营收、研发合计、主营占比、IP数量、市占率等条件不得凭记忆或推断填写，必须与当年度工信部通知核对
2. **禁止编造市场数据**：市场占有率≥10%或国内前三的判定，必须有权威第三方来源（行业协会报告/券商研报/招股书/官方统计/头部客户采购数据），**禁止以客户口头估算或AI推算作为申报依据**
3. **禁止编造卡脖子/进口替代表述**：卡脖子技术论证、进口替代分析必须基于真实技术差距与可查证的事实（技术对标报告/检测报告/客户验证），禁止夸大
4. **禁止推断关键数据**：营收、研发费用、IP数量等字段必须以审计报告、所得税申报表、专利证书等官方文件为准
5. **禁止跳过脚本执行**：所有 `python C:/Users/T203-15/.ponos/skills/_common/xxx.py` 命令必须通过 Bash 真正执行，不得"阅读脚本逻辑自行编写等效代码"
6. **禁止跳过审核步骤**：审核验证步骤必须执行且通过，未通过时不得继续后续步骤
7. **禁止自行兜底**：脚本报错时不得自行编写兜底代码，必须停止并告警由用户决定
8. **禁止跨技能污染**：仅读取当前项目留痕，不跨项目读取

### 数据来源优先级（高 → 低）

- **官方文件**（审计报告/所得税申报表/证书/工信部通知原文）：✅ 可直接采用
- **权威第三方数据**（行业协会/券商研报/招股书/官方统计）：⚠️ 需标注来源、报告日期、统计口径后采用
- **项目内数据**（企业提供的经营数据）：⚠️ 需与官方文件交叉验证后采用
- **缺失**：❌ 不得编造，必须标注"待补充"

### 无法确认时的处理

- **当年度工信部通知未检索到**：停止申报流程，提示用户检索官方原文，禁止用旧版条件直接替代
- **市场占有率无法佐证**：标注"待补充（需行业协会/研报数据）"，禁止估算后写入申报书
- **卡脖子定位无法论证**：暂停该论证章节，提示用户提供技术对标/检测佐证，不得自行拔高表述
- **脚本报错**：立即停止，输出错误日志，由用户决定修复方案
- **审核不通过**：停止后续步骤，输出 ERROR 清单，由用户决定整改方案

## 申报条件总览（政策框架基准，以当年度工信部通知为准）

| 条件项 | 要求 | 数据来源 |
|--------|------|---------|
| 前置条件 | 专精特新中小企业（有效期内） | 工信部门认定名单 |
| 营业收入 | ≥5000万元（或满足当年度替代条款） | 审计报告 |
| 主营业务收入占比 | ≥90% | 审计报告/科目明细 |
| 近两年研发费用合计 | ≥1200万元 | 辅助账/所得税申报表 |
| Ⅰ类知识产权 | ≥4项（有效期内，部分按折算条款） | 专利证书 |
| 市场占有率 | ≥10%（国内细分市场）或国内排名前三 | 权威第三方数据 |

**核心论证材料（本技能独有，评审权重高）**：
1. **卡脖子技术论证**：技术断点定位 → 国内外技术差距对比 → 企业突破点与成果 → 客户/检测佐证
2. **产业链关键环节定位报告**：所在产业链图谱 → 企业所处环节的关键性 → 补链强链作用
3. **市场占有率数据佐证包**：细分市场界定 → 市场容量 → 企业销售额 → 占有率测算 → 第三方报告
4. **进口替代分析**：进口依赖产品清单 → 替代可行性论证 → 已实现的替代案例/订单

## 工作流

### 第一步：项目初始化（强制执行，不可跳过）

```bash
python C:/Users/T203-15/.ponos/skills/_common/project_context_manager.py init --enterprise "{企业名称}" --year {申报年份}
```

初始化后读取 file_map.json（文件分布）与 experience_base.json（历史经验）。

### 第二步：前置条件确认

1. 核对企业在"专精特新中小企业"认定名单中的有效状态
2. 未认定 → 暂停，提示用户：小巨人必须以专精特新为前置，先走 yfwx-zhuanjingtexin
3. 输出《前置条件确认表》

### 第三步：技术先进性深度论证（卡脖子论证）

1. 收集企业技术对标材料（国内外竞品技术参数对比/检测报告/客户验证报告）
2. 界定所在细分领域的技术断点，论证企业技术所处位置
3. 撰写《卡脖子技术突破论证报告》，**每个论断必须对应可查证的事实来源**，禁止使用"国内领先""国际先进"等无据表述
4. 交叉验证：技术论断与IP、RD、检测报告数据一致

### 第四步：产业链补链强链论证

1. 绘制产业链图谱（上游原料/设备 → 本企业环节 → 下游客户）
2. 论证本企业环节的关键性与不可替代性（客户集中度/替换成本/独家供应）
3. 撰写《产业链关键环节定位报告》，附客户合同、配套清单佐证

### 第五步：市场排名数据包准备

1. 界定细分市场（产品品类+地域范围+统计口径）
2. 收集市场容量与竞争格局数据（行业协会报告/券商研报/招股书/官方统计）
3. 计算企业市场占有率（企业营收 ÷ 细分市场容量），标注计算过程
4. 多来源数据冲突时暂停确认（A类），由用户指定以哪个来源为准
5. 输出《市场排名数据包》：测算表 + 全部来源报告原件

### 第六步：申报书撰写

1. 按工信部当年度申报书模板逐章撰写
2. 数据引用必须标注来源（审计报告页次/研报名称/报告日期）
3. 卡脖子、进口替代章节严格执行第三步、第四步的论证结论，不得超范围拔高

### 第七步：国家级审核对标

1. 按当年度通知的评审要点（技术/市场/创新/经营四维度）逐条自查
2. 输出《国家级审核对标表》：评审要点 → 企业响应材料 → 证据文件 → 达标状态
3. 未达标项 → 输出补充计划，由用户决定是否补充或放弃该要点

### 最终步：审核验证（必须通过才能提交）

1. **条件审核**：全部硬指标达标（前置/营收/主营占比/研发/IP/市占率）
2. **真实性审核**：卡脖子、进口替代、产业链论述均有事实来源；市占率测算过程完整可复核
3. **一致性审核**：申报书数据与审计报告、IP证书、专精特新申报数据一致
4. **政策原文审核**：所有条件与当年度工信部通知逐条核对一致（含替代条款）
5. **文件审核**：调用命名规范检测（naming_compliance.py），PDF格式与大小合规
6. 生成《小巨人申报审核报告》，输出 ERROR 清单或审核通过结论
