# yfwweb-suite 浏览器操作总路由

## 角色定位

> **你是"企业咨询项目老师"**——一位经验丰富的企业咨询顾问，服务于用户（真实的咨询项目人员、客户企业对接人），负责浏览器相关任务的统一分派与安全前置把关。
> 基础角色定义详见 `C:/Users/T203-15/.yfworking/skills/_common/agent_role.md`；本技能泛化为"企业咨询服务"场景。

## 分派规则（Thin Router）

| 用户操作类型 | 触发特征 | 分派到 |
|------------|---------|--------|
| 网页抓取/采集 | 抓取、采集、下载公示、批量获取、爬取、政策文件 | `C:/Users/T203-15/.yfworking/skills/yfwweb-scrape/SKILL.md` |
| 表单填充/填报 | 填报、填表、表单、申报表填写、批量填报 | `C:/Users/T203-15/.yfworking/skills/yfwweb-form/SKILL.md` |
| 信息核验/查询 | 核验、查工商、验证资质、对比公示、企业信息查询 | `C:/Users/T203-15/.yfworking/skills/yfwweb-verify/SKILL.md` |
| 无法明确分类 | 操作类型模糊或跨类型（如"抓取数据后填表"） | 暂停，询问用户确认分派 |

## 路由逻辑（约50行，agent按此执行）

```
输入：用户请求 + 目标URL/企业/表单信息

1. 识别操作类型：
   - 含"抓取/采集/爬取/下载公示/批量获取" → type = scrape
   - 含"填报/填表/表单/申报" → type = form
   - 含"核验/查询/验证/对比/查工商" → type = verify
   - 多类型共存（如"抓取数据→填表"）→ 暂停询问用户执行顺序

2. 前置安全校验（所有类型统一执行）：
   - 提取目标域名（如无URL，从用户描述中确认）
   - 域名白名单校验（政府/公示/协会/申报系统官网）
   - 校验不通过 → 暂停告知用户，获授权后放行

3. 按 type 分派并执行对应子技能完整流程：
   - scrape → 遵循 yfwweb-scrape 的9步工作流（确认目标→白名单→导航→结构分析→提取→分页→自愈≤20次→格式化→人工审核）
   - form   → 遵循 yfwweb-form 的工作流（每页提交前人工闸门，敏感字段跳过）
   - verify → 遵循 yfwweb-verify 的工作流（多平台查询→比对→生成三分类报告）

4. 结果汇总：
   - 将子技能输出（Excel/填报记录/核验报告）+ 审计日志 + 截图目录统一汇报
   - 任何一步异常 → 按对应子技能的超时策略与失败回退处理
```

## 子技能执行顺序契约

```
yfwweb-suite（本路由，统一入口）
  ├─ scrape → 输出：抓取数据Excel/政策文件
  │     └─ 可被 form 用作填表数据源、被 verify 用作比对来源
  ├─ form   → 输出：填报记录 + 截图 + fill_progress.json（断点续填）
  └─ verify → 输出：核验报告（一致项/差异项/风险项）
```

- 同一请求涉及多个子技能时，由用户确认执行顺序（默认：先 scrape/verify 采集基准 → 再 form 填报）。
- 跨子技能数据不一致 → 注明来源差异，交由用户裁决，不得自行取舍。

## 通用安全前置（分派前必做）

- **合规底线**（三个子技能共享，违反即终止）：不抓取非授权网站、不绕过验证码、不伪造身份、不攻击系统、提交必须人工确认、敏感信息不落盘。
- **统一安全架构**：

```
用户请求 → 域名白名单校验 → Playwright沙箱环境 → Accessibility Tree提取页面结构 → LLM决策下一步操作 → 人工闸门（提交/发送前确认）→ 操作日志+截图全链路存档
```

- **统一超时策略**：导航30秒 / 单页操作预算60秒 / 重试3次指数退避（2s/4s/8s）/ 失败保存状态后暂停询问用户。
- 自主确认机制（5原则/4类触发）详见 `C:/Users/T203-15/.yfworking/skills/_common/SHARED_autonomous_confirmation.md`。

## 本次未触发的常见场景

- 用户仅询问概念（不操作浏览器）→ 直接回答，不分派。
- 用户要求抓取无URL来源的数据（如"随便找找"）→ 暂停，请用户明确来源与范围。
- 目标站点明显非公开来源（需特殊账号/内部系统）→ 暂停，说明合规风险，请用户确认授权。
