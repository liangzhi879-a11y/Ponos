## 角色定位

本技能负责高新技术企业认定中**PS高新产品（服务）明细表**的生成与模板注入。数据来源于成果转化表和PS证明材料（合同/发票）。

## 输出文件

- `{企业名称}-高新技术产品（服务）明细表.xlsx`
- 存放到 `00_核心表格/` 目录

## 核心脚本

```bash
# 生成PS表
python {{YFW_SKILLS}}/_common/generate_ps_table.py --project-root "."
# 校验PS表
python {{YFW_SKILLS}}/_common/validate_ps_table.py --input "00_核心表格/PS表.xlsx"
```

### 字段提取方法

```python
def extract_ps_fields(ps_product, year):
    """
    从产品信息中提取字段
    ps_product: dict，包含产品基本信息
    year: int，申报年份
    """
    ps_data = {
        '产品（服务）编号': ps_product['ps_id'],  # 如PS01
        '产品（服务）名称': ps_product['name'],
        '技术领域（一级）': ps_product['tech_field_1'],
        '技术领域（二级）': ps_product['tech_field_2'],
        '技术领域（三级）': ps_product['tech_field_3'],
        '技术来源': ps_product['tech_source'],  # "企业自有技术"
        '上年度销售收入（万元）': ps_product['revenue'],
        '是否主要产品（服务）': ps_product['is_main_product'],  # "是"或"否"
        '知识产权编号': ','.join(ps_product['ip_ids']),
        '关键技术及主要技术指标（限400字）': ps_product['key_tech'],
        '与同类产品（服务）的竞争优势（限400字）': ps_product['competitive_advantage'],
        '知识产权获得情况及其对产品（服务）在技术上发挥的支持作用（限400字）': ps_product['ip_support'],
    }
    return ps_data
```

## 长文本字段生成规范（v1.39.0）

PS表的3个长文本字段必须由 agent 按提示词逐PS生成，禁止算法拼接或截断：

| 字段 | 字数要求 | 生成方式 |
|------|:--------:|---------|
| 关键技术及主要技术指标 | 350-400字 | 结合PS产品技术文档生成，分"关键技术"和"主要指标"两部分 |
| 与同类产品的竞争优势 | 350-400字 | 结合市场定位和产品特色，分点列出竞争优势 |
| 知识产权支持作用 | 350-400字 | 列出具体专利号和名称，说明知识产权对产品的核心支撑 |

### 撰写要求

1. 技术领域必须从《国家重点支持的高新技术领域》中选择
2. 关键技术要分"关键技术"和"主要指标"两部分
3. 竞争优势要分点列出，突出产品特色
4. 知识产权获得情况要列出具体专利号和名称
5. 支持作用要说明知识产权对产品的核心支撑
6. 上年度销售收入必须与审计报告一致
7. 关联知识产权必须与成果转化表、研发活动表一致
8. 不出现编号（PS01/IP01），不出现夸大词（领先/首创）
9. 语言正式，采用概括性表述

## 时间约束

```
PS上年度收入 = 申报年份前一年的收入
示例：2025年申报 → 上年度 = 2024年收入
PS收入必须与审计报告一致
```

### PS产品名称对标规则（v1.34.0）

1. PS表中「产品名称」以高新申请书中的PS名称为唯一基准
2. 发票「货物名称」与PS名称不一致时，在发票备注栏标注对应PS编号
3. 不允许从发票货物名称反推PS产品名称
4. 一个PS产品可对应多个不同的发票货物名称，但必须一一标注映射关系

## 关联校验

### IP编号关联校验
PS表中的知识产权编号必须是IP表中知识产权编号的子集。

```python
def validate_ps_association(ps_table, ip_table):
    ip_ids = set(ip_table['知识产权编号'].tolist())
    for _, row in ps_table.iterrows():
        ps_ip_ids = [x.strip() for x in row['知识产权编号'].split(',') if x.strip()]
        for ip_id in ps_ip_ids:
            if ip_id not in ip_ids:
                raise ValueError(f"PS表中的{ip_id}在IP表中不存在")
```

## 三角验证

### PS零RD关联的修复策略

**项目教训**（友联普达）：PS01占收入83%却零RD关联——因为PS01曾是电机贸易品，而18个RD都是电路板方向。

```
修复步骤：
1. 诊断：确认PS01的货物关键词与RD方向不匹配
2. 重新定义PS名称：加入桥接词
   旧名称：永磁同步电机 → 新名称：驱动控制与执行模组
   理由：核心研发是驱动控制电路板，外购电机作为执行组件
3. 重新匹配：新PS名称下的桥接词匹配到电路板RD
4. 每个PS必须有RD支撑——这是基本逻辑，不是可选优化
```

### 匹配结果人工复核清单（必执行）

```
□ 每个PS的关联RD数量 > 0（零关联→立即修复）
□ 高收入占比PS（>20%）有充分RD支撑
□ 闲置IP数为0
□ 跨领域匹配的RD-IP有合理的技术基础说明
□ 时间约束违规的RD-IP有合理的例外说明
```
