# yfwdoc-template — 企业文档模板库管理

企业咨询场景的文档模板库管理技能：收集品牌素材、固化品牌规范（颜色/字体/Logo/页眉页脚）、创建/更新文档模板、质量审核、注册到模板库，供 yfwdoc-word/pptx/excel 三个文档技能统一调用。

## 3. 合规红线（不可逾越）

1. **模板禁止夹带假数据**：模板中不允许出现虚构示例（假公司名/假文号/示例条款/占位假数据），需要示例的必须显式标注"示例内容"。
2. **禁止覆盖已有版本**：模板更新只能新增版本号（`{类型}_{品牌}_v{版本}.{ext}`），历史版本永久保留，禁止静默覆盖。
3. **素材版权**：Logo/字体/图片未授权或来源不明时禁止入库，向用户说明风险。
4. **注册表必须真实**：template_index.json 的每个条目必须对应真实存在的模板文件（注册后校验 checksum）。
5. **审核未通过禁止注册**：质量审核（步骤4）不通过的模板不得进入模板库正式生效。

## 5. 执行顺序契约

```
步骤1 收集品牌素材 → 步骤2 定义品牌规范 → 步骤3 创建/更新模板
→ 步骤4 质量审核 → 步骤5 注册到模板库
```

- 步骤2 品牌规范确认后才能创建模板；步骤3 只基于已确认规范
- 步骤4 审核全项通过才可进入步骤5；任一审核项不通过，修复后复检
- 步骤5 注册生效是正式动作，注册前向用户说明将影响 word/pptx/excel 的默认选用

## 6. 工作流

### 步骤1：收集品牌素材

**输入**：用户需求（"固化品牌"或"新建模板"）
**操作**：收集并登记：
- **Logo**：源文件（优先矢量 SVG/AI 或 ≥300dpi 透明PNG），记录授权状态
- **字体**：正文字体/标题字体清单（含授权），无授权字体记录替代方案
- **主题色**：主色/辅助色值（HEX），来源（品牌手册/官网/用户指定）
- **页眉页脚**：企业名称标准写法、页眉页脚样式参考、联系电话/网址
- **既有模板**：用户现有历史模板（可作改版基础）

**输出**：《素材清单》（每项含来源与授权状态）
**验证标准**：Logo/字体/色值均来源明确；授权状态不明或Logo分辨率不足时向用户提示风险，确认后才继续

### 步骤2：定义品牌规范

**输入**：素材清单（用户确认后）
**操作**：生成并固化品牌规范文件 `_templates/brand_spec_{企业}.json`：

```json
{
  "brand": "企业名称",
  "primary_colors": ["#1B4F9C", "#C8A45D"],
  "accent_colors": ["#E8EEF7"],
  "fonts": {"heading": "微软雅黑", "body": "宋体"},
  "logo_path": "_templates/assets/logo.png",
  "header_footer": {"page_header": "企业名称", "page_footer": "第X页 共Y页 | 企业名称"},
  "standard_docs": ["红头文件", "通知", "函", "会议纪要", "简报", "标书", "合同", "PPT", "Excel报表"]
}
```

**输出**：`brand_spec_{企业}.json`（用户逐项确认）
**验证标准**：色值/字体/Logo/页眉页脚与用户确认一致；从既有文档推断的规范已说明推断依据并经用户确认（C类）

### 步骤3：创建/更新模板

**输入**：品牌规范
**操作**：
- **新建**：按文档类型逐一创建模板，应用品牌规范——
  - 公文类：红头文件（版头/文号/主送/正文/落款）、通知、函、会议纪要、简报
  - 商务类：标书封面+目录+正文骨架、方案书
  - 法律类：合同框架（条款留白，不填示例条款）
  - 演示类：PPT母版（16:9，主题色板+Logo+页脚，python-pptx 生成）
  - 报表类：Excel报表模板（标题行/表头样式/汇总公式区，openpyxl 生成）
- **更新**：仅基于既有模板改版，新文件命名 `{类型}_{品牌}_v{版本}.{ext}`，旧版保留
- 生成后按技术栈命令打开校验模板可用

**输出**：模板文件 + 变更说明
**验证标准**：模板可正常打开、样式与品牌规范一致、无示例假数据残留；更新场景保留了历史版本

### 步骤4：质量审核

**输入**：新建/更新模板
**操作**：按审核清单逐项检查：
- [ ] 页面尺寸/边距/页眉页脚正确（公文类符合公文格式要求）
- [ ] 字体统一且已指定（PPTX/PDF场景考虑字体嵌入）
- [ ] Logo清晰（≥300dpi或矢量），无变形拉伸、无白底瑕疵
- [ ] 颜色全部来自 brand_spec 色板
- [ ] 样式层级完整（标题1/2/3、正文、表格、列表样式齐备）
- [ ] 无残留占位假数据（或已显式标注"示例内容"）
- [ ] 文件命名符合版本规范

**输出**：《审核结论》（通过 / 整改项清单）
**验证标准**：全部通过才可注册；整改项修复后重新执行本步骤复检

### 步骤5：注册到模板库

**输入**：审核通过的模板
**操作**：
1. 移动/确认模板位于 `_templates/`，计算 checksum
2. 更新注册表 `template_index.json`，注册条目：
   ```json
   {
     "id": "redhead_v1",
     "name": "红头文件模板",
     "type": "word",
     "brand": "企业名称",
     "version": "1.0.0",
     "path": "_templates/红头文件_企业名称_v1.docx",
     "keywords": ["红头文件", "发文", "通知"],
     "updated_at": "2026-08-04",
     "checksum": "md5值"
   }
   ```
3. 新版本登记时更新 version 与 checksum，历史条目保留（完整版本历史）
4. 输出注册摘要，告知用户该模板将供 yfwdoc-word/pptx/excel 默认选用

**输出**：更新后的 `template_index.json` + 注册摘要
**验证标准**：注册后抽查——按关键词可检索、路径文件真实存在且 checksum 匹配；版本历史完整无覆盖
