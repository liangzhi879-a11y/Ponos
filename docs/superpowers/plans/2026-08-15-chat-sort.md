# 会话集拖拽排序 + 会话列表排序 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 会话集支持拖拽排序（手动顺序持久化），会话列表支持 4 种排序模式（最近更新/创建时间/标题/手动，跨重启记住）。

**Architecture:** 纯前端改动（chatStore + uiStore + Sidebar + i18n）。`conversationSets` 数组顺序即手动顺序（partialize 已原样持久化）；排序模式存 uiStore 并加入其 partialize 白名单跨重启记住。排序仅作用于 unpinned 主列表（pinned 区不参与），展示层排序不改 `conversations` 数组；非手动模式拖拽会话在 dragStart 立即切回 manual（保证 drop 索引与展示一致）。

**Tech Stack:** React 18 + Zustand（persist）+ lucide-react + i18n（zh-CN/en-US）+ Tailwind 类名。前端无单测基建，验证门槛为 `npm run typecheck` 0 错误 + 手测清单。

## Global Constraints

- `ponos-kernel/` 零修改；`server/`、`electron/` 零修改（纯前端功能）。
- 前端无单测基建（现有测试仅覆盖 server）→ 每任务验证 = `npm run typecheck` 0 错误。
- `uiStore` persist 有**自定义 partialize 白名单**（uiStore.ts:249-257）——新增 `chatSortMode` 必须加入白名单，否则不持久化。
- `chatStore` 的 `partialize` 已原样持久化 `conversationSets` → 数组顺序即手动顺序，不需要改 partialize。
- 排序不改变 `conversations` 数组顺序（仅展示层排序）；`manual` 模式展示即 store 顺序。
- 排序仅作用于 unpinned；pinned 区保持手动顺序不参与。
- 会话集仅手动顺序（不参与排序模式）。
- 导出顺序、`autoOrganize` 语义不变。
- `ponos-chat` / `ponos-ui` persist key 不变。
- 提交信息风格：`feat(chat): ...`；提交只含本任务列出的文件，不碰 `build/installer.nsh`（既有无关改动）与未跟踪文件。

```tsx
  // 会话集拖拽排序（仅手动顺序；会话集不参与排序模式）
  const handleSetDragStart = (setId: string) => { setDragSetId(setId) }
  const handleSetDragOver = (e: React.DragEvent, setId: string) => {
    e.preventDefault()
    e.dataTransfer.dropEffect = 'move'
    if (setId !== dragSetId) setDragSetOverId(setId)
  }
  const handleSetDragLeave = (setId: string) => {
    if (dragSetOverId === setId) setDragSetOverId(null)
  }
  const handleSetDrop = (setId: string) => {
    setDragSetOverId(null)
    if (!dragSetId || dragSetId === setId) { setDragSetId(null); return }
    const from = conversationSets.findIndex(s => s.id === dragSetId)
    const to = conversationSets.findIndex(s => s.id === setId)
    if (from >= 0 && to >= 0) reorderConversationSets(from, to)
    setDragSetId(null)
  }
  const handleSetDragEnd = () => { setDragSetId(null); setDragSetOverId(null) }
```

- [ ] **Step 5: 会话集头部拖拽绑定**
