# MCP 顶层面板与授权模型 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 MCP 从设置窗提升为与会话/任务同级的顶层标签，新增按服务器的三档授权（关闭/仅测试/公开/指定 agent），并让面板显示内核**真实接入状态**，修掉"添加成功却用不上"的误导。

**Architecture:** 内核侧在既有 `createMcpRegistry` 上增加"按 agentId 实时组装视图 + `snapshot()` 上报"；桥侧新增 `GET /mcp/status` 并复用既有的 spawn 签名比对机制（`_spawnEnvSig` 同款）让配置变更在**下一条消息**时自动生效；前端新增第 8 个 rail 与 `McpView`（状态条 + 卡片 + 工具清单），把 665 行的 `McpPanel` 拆成 `McpConfigEditor`（配置）+ `McpView`（视图）。

**Tech Stack:** Node 24（`.mjs`，零新依赖）、React 18 + TypeScript + zustand、`node --test` 原生测试（`src` 侧走 Node 原生 TS，相对导入须带 `.ts` 后缀）。

**Spec:** `docs/superpowers/specs/2026-09-16-mcp-panel-design.md`

## Global Constraints

- **零新依赖**：只用 Node 内置 + 既有依赖（`node:crypto`、`node:http` 等）。
- **内核 `view()` 必须保持同步、绝不阻塞**（`kernel/tools.mjs` 的 `toolSchemas` 直接调用它）。
- **配置字段沿用 camelCase**（与既有 `timeoutMs` 一致）：`enabled`、`expose.mode`、`expose.bindAgents`（**不是** `bind_agents`）。
- **权限 fail-closed**：`bound` 而 `bindAgents` 为空 ⇒ 无人可见，**绝不退化成 `public`**。
- **存量兼容**：`enabled` 缺省 `true`、`expose.mode` 缺省 `public` ⇒ 无新字段的旧配置行为完全不变。
- **`enabled` 只认显式 `false`**：其它值（含缺省、`'false'` 字符串）一律视为开启——解析歧义不该悄悄关掉用户的服务器。
- **`bound` 对主会话不可见**：`agentId` 为空 ⇒ `bound` 返回 `null`（与 `kernel/dyntools.mjs` 的 `visibilityOf` 同义）。
- **agentId 单一来源**：内核侧一律用 `args.agent`（与 `buildWorkflowTools` 同源），不得另立来源。
- **不引入轮询**：状态同步走既有"hook 收 system 事件 → 写 zustand store → 面板读 store"。
- **`GET /mcp` 与 `GET /mcp/status` 绝不抛**（GUI 要能显示"文件坏了"），且未知路径必须返回 `null` 交给后续路由。
- **改 `RailId` 必须同时改 `RAIL_IDS`**：只改一处会让落盘值被 `sanitizeRail` 静默清成 `'task'`（表现为"选中后刷新弹回任务"）。
- **前端相对导入带 `.ts` 后缀**（`node --test` 走 Node 原生 TS，不认 `@/` alias）；**组件内不得把 `t` 放进依赖数组**（`src/lib/hooksDeps.test.ts` 静态守卫会拦）。
- **i18n 无 parity 测试**：zh/en 必须人工对齐。
- **不触碰并行会话的文件**：`kernel/engine.mjs`、`kernel/fidelity.mjs`、`kernel/health.mjs`、`kernel-tests/fidelity-anchor-loop.test.mjs`；提交一律用显式路径 `git add`。
- **新增内核文件必须手工同步到 `release/YFWorking/`**（无脚本自动同步；同步是"确认存在"而非只看"一致"）。
- 测试命令：单文件 `node --test --test-timeout=60000 <path>`；全量 `npm test`（= `node --test --test-timeout=300000 "shared/**/*.test.mjs" "server/*.test.mjs" "electron/*.test.mjs" "kernel-tests/*.test.mjs" "src/**/*.test.ts"`）。

```js
/** 授权模式：private = 连上但不给任何 AI（仅供面板测试）/ public = 所有 agent / bound = 仅 bindAgents 列出的 agent */
export const EXPOSE_MODES = ['private', 'public', 'bound']

/**
 * 归一化 `expose`。缺省 `{mode:'public'}` —— 这是**刻意与工作流不同**的一处：
 * `kernel/dyntools.mjs` 的可见性缺省是 private，而存量 `mcp.json` 里根本没有 `expose` 字段，
 * 若这里缺省 private，升级后所有 MCP 工具会突然消失，用户会认为功能坏了。
 * 向后兼容优先：没有该字段 = 沿用现在的行为 = 所有 agent 可用。
 */
export function normalizeExpose(raw) {
  if (raw === undefined || raw === null) return { ok: true, expose: { mode: 'public', bindAgents: [] } }
  if (typeof raw !== 'object' || Array.isArray(raw)) return { ok: false, error: 'expose 必须是对象' }
  const mode = raw.mode === undefined || raw.mode === null ? 'public' : String(raw.mode)
  if (!EXPOSE_MODES.includes(mode)) {
    return { ok: false, error: `expose.mode 只能是 ${EXPOSE_MODES.join(' / ')}（收到 "${mode}"）` }
  }
  const bindAgents = []
  if (raw.bindAgents !== undefined && raw.bindAgents !== null) {
    if (!Array.isArray(raw.bindAgents)) return { ok: false, error: 'expose.bindAgents 必须是数组' }
    for (const a of raw.bindAgents) {
      const s = String(a ?? '').trim()
      if (!s) return { ok: false, error: 'expose.bindAgents 里不能有空项' }
      if (!bindAgents.includes(s)) bindAgents.push(s)   // 去重保序：重复项会让界面显示重复标签
    }
  }
  // fail-closed 的**写侧**对应：bound 却没列出任何人 ⇒ 该服务器无人可用，
  // 几乎总是漏填而非本意。在保存时就报错，好过保存后发现"授权了却没生效"。
  if (mode === 'bound' && !bindAgents.length) {
    return { ok: false, error: 'expose.mode 为 bound 时须至少指定一个 agent（否则没有任何 AI 能用）' }
  }
  return { ok: true, expose: { mode, bindAgents } }
}

/** `enabled` 只认显式 false：解析歧义（"false"、0、null）一律视为开启，宁可多连一次也不静默停用 */
export function normalizeEnabled(raw) {
  return raw === false ? false : true
}

/**
 * 某条目对指定 agent 的可见性。`agentId` 为空 = 主会话。
 * @returns {'public'|'bound'|null} null = 不可见
 *
 * 与 `kernel/dyntools.mjs` 的 `visibilityOf` **同名同义**（bound 对主会话不可见），
 * 用户不必学第二套规则。任何未知/畸形输入一律返回 null —— 权限判定必须向"更严"一侧失败。
 */
export function mcpVisibilityOf(entry, agentId) {
  if (!entry || entry.enabled === false) return null
  const mode = entry.expose?.mode || 'public'
  if (mode === 'private') return null
  if (mode === 'public') return 'public'
  if (mode === 'bound') {
    if (!agentId) return null
    const list = Array.isArray(entry.expose?.bindAgents) ? entry.expose.bindAgents : []
    return list.includes(String(agentId)) ? 'bound' : null
  }
  return null
}

/** 稳定序列化：键排序，便于做内容签名（键序不同必须得到同一签名，否则重存一次就白重启内核） */
function stableStringify(v) {
  if (Array.isArray(v)) return `[${v.map(stableStringify).join(',')}]`
  if (v && typeof v === 'object') {
    return `{${Object.keys(v).sort().map(k => `${JSON.stringify(k)}:${stableStringify(v[k])}`).join(',')}}`
  }
  return JSON.stringify(v === undefined ? null : v)
}

/**
 * 配置内容签名（16 位十六进制）。桥用它判断"磁盘配置是否比运行中的内核新"：
 * 不一致 ⇒ 重放内核（--resume，上下文不丢）。**必须包含 enabled/expose**——
 * 授权变更同样需要重载，否则用户改了授权却看不到效果。
 */
export function mcpConfigSig(servers) {
  return createHash('sha256').update(stableStringify(servers || {})).digest('hex').slice(0, 16)
}
```

// src/components/mcp/mcpStatus.ts —— MCP 状态判定的纯逻辑。
// 单独成文件是为了能被测试直接相对导入（src 侧测试走 Node 原生 TS，不认 @/ alias）。
export type McpKernelSnapshot = {
  servers: Record<string, { tools: string[]; expose: string }>
  failed: Record<string, string>
  disabled: string[]
  configSig: string
}
export type McpStatusCache = {
  ok: boolean
  error?: string
  config: { path: string; sig: string | null }
  kernel: McpKernelSnapshot | null
  stale: boolean
}

/**
 * 'unknown' = 内核本次运行还没上报过 —— **必须与"已生效但 0 个工具"区分开**，
 * 否则界面会在内核根本没起来的时候谎称"已接入 0 个"，把"没生效"包装成"生效了但空"。
 */
export function stalenessOf(cache: McpStatusCache | null): 'unknown' | 'fresh' | 'stale' {
  if (!cache || !cache.kernel) return 'unknown'
  return cache.stale ? 'stale' : 'fresh'
}

/** 汇总内核快照：服务器总数含失败的（面板要能报出失败），工具数只数成功接入的 */
export function kernelSummary(snap: McpKernelSnapshot) {
  const names = Object.keys(snap.servers || {})
  const failedNames = Object.keys(snap.failed || {})
  return {
    totalServers: names.length + failedNames.length,
    totalTools: names.reduce((a, n) => a + (snap.servers[n].tools?.length || 0), 0),
    failedNames,
    disabledNames: [...(snap.disabled || [])],
  }
}
```

export type ExposeMode = 'private' | 'public' | 'bound'
export type AuthLevel = 'off' | 'test' | 'public' | 'bound'

type CfgLike = {
  enabled?: boolean
  expose?: { mode?: ExposeMode; bindAgents?: string[] }
  [k: string]: unknown
}

/** 配置 → 界面档位（四档：关闭 / 仅测试 / 公开 / 指定 agent） */
export function authLevelOf(cfg: CfgLike | null | undefined): AuthLevel {
  if (!cfg) return 'public'
  if (cfg.enabled === false) return 'off'
  const mode = cfg.expose?.mode || 'public'   // 缺省 public：存量配置行为不变
  return mode === 'private' ? 'test' : mode
}

/**
 * 界面档位 → 配置。**保留 bindAgents 列表**：切走再切回时不必重选
 * （列表在非 bound 档不生效，留在配置里无害；而丢掉它会让用户在档位间犹豫时反复重填）。
 */
export function applyAuthLevel<T extends CfgLike>(cfg: T, level: AuthLevel): T {
  const list = Array.isArray(cfg?.expose?.bindAgents) ? cfg.expose.bindAgents : []
  if (level === 'off') return { ...cfg, enabled: false, expose: { mode: 'public', bindAgents: list } }
  if (level === 'test') return { ...cfg, enabled: true, expose: { mode: 'private', bindAgents: list } }
  if (level === 'bound') return { ...cfg, enabled: true, expose: { mode: 'bound', bindAgents: list } }
  return { ...cfg, enabled: true, expose: { mode: 'public', bindAgents: list } }
}
```

```ts
export function validateRowsMsg(rows: Array<{
  key: string; name: string; transport: 'stdio' | 'http'
  config: { command?: string; url?: string; enabled?: boolean; expose?: { mode?: ExposeMode; bindAgents?: string[] } }
}>): string {
  const seen = new Set<string>()
  for (const r of rows) {
    const name = String(r.name || '').trim()
    if (!name) return '服务器名称不能为空'
    if (seen.has(name)) return `服务器名称重复：${name}`
    seen.add(name)
    if (authLevelOf(r.config) === 'off') continue   // 关闭的服务器没有必填项：连都不连，凭什么要求填命令
    if (r.transport === 'http' && !String(r.config.url || '').trim()) return `服务器 "${name}" 缺少 URL`
    if (r.transport === 'stdio' && !String(r.config.command || '').trim()) return `服务器 "${name}" 缺少命令`
    if (authLevelOf(r.config) === 'bound' && !(r.config.expose?.bindAgents || []).length) {
      return `服务器 "${name}" 指定了"仅特定 agent"，但一个 agent 都没选`
    }
  }
  return ''
}
```

                              const on = (row.config.expose?.bindAgents || []).includes(a.id)
                              return (
                                <label key={a.id} className="flex items-center gap-1 text-xs">
                                  <input
                                    type="checkbox"
                                    checked={on}
                                    onChange={() => patchConfig(row.key, r => {
                                      const cur = r.config.expose?.bindAgents || []
                                      const next = on ? cur.filter(x => x !== a.id) : [...cur, a.id]
                                      return { ...r, config: { ...r.config, expose: { mode: 'bound', bindAgents: next } } }
                                    })}
                                  />
                                  {a.name || a.id}
                                  {a.disabled ? <span className="text-muted-foreground">（已停用）</span> : null}
                                </label>
                              )
                            })}
                          </div>
                        )}
```

```tsx
// src/components/mcp/McpView.tsx —— MCP 顶层面板。
//
// 顶部状态条是**内核真值**（内核就绪后上报、桥缓存、GET /mcp/status 取回），
// 而每张卡片里的"连接测试"只是**面板自己发起的探测**，两者含义不同，界面上必须分开写：
// 混在一起正是用户"添加成功却找不到调用入口"的来源——探测通过只说明这台连得上，
// 不代表内核已经把它接进 AI 的工具表。
import { useEffect } from 'react'
import { useTranslation } from '@/i18n/useTranslation'
import { useMcpStore, stalenessOf, kernelSummary } from '@/stores/mcpStore'
import { McpConfigEditor } from '@/components/mcp/McpConfigEditor'

export function McpView() {
  const { t } = useTranslation()
  const { status, load, loading } = useMcpStore()

  // 挂载时拉一次：内核可能在面板打开前就已上报（事件早错过了，但桥侧有缓存）。
  // 此后靠 mcp_status 事件推送更新，**不轮询**。
  useEffect(() => { void load() }, [load])

  const stale = stalenessOf(status)
  const sum = status?.kernel ? kernelSummary(status.kernel) : null

  return (
    <div className="flex h-full flex-col overflow-hidden">
      <div className="border-b px-4 py-3">
        <div className="flex items-center justify-between">
          <h2 className="text-sm font-medium">{t('settings.mcpTitle')}</h2>
          <button className="text-xs text-muted-foreground hover:underline" onClick={() => void load()}>
            {loading ? t('settings.mcpLoading') : t('settings.mcpRefresh')}
          </button>
        </div>

        {/* ---- 内核真实接入状态 ---- */}
        <div className="mt-2 space-y-1 text-xs">
          {stale === 'unknown' && (
            <div className="text-muted-foreground">{t('settings.mcpKernelNever')}</div>
          )}
          {stale !== 'unknown' && sum && (
            <div className="text-emerald-500">
              {t('settings.mcpKernelOk', { servers: sum.totalServers, tools: sum.totalTools })}
            </div>
          )}
          {stale === 'stale' && (
            <div className="text-amber-400">{t('settings.mcpStaleHint')}</div>
          )}
          {sum?.failedNames.map(n => (
            <div key={n} className="text-red-400">
              {t('settings.mcpFailedOne', { name: n, reason: status?.kernel?.failed?.[n] || '' })}
            </div>
          ))}
          {!!sum?.disabledNames.length && (
            <div className="text-muted-foreground">
              {t('settings.mcpDisabledOne', { names: sum.disabledNames.join('、') })}
            </div>
          )}
          {status?.error && <div className="text-red-400">{status.error}</div>}
        </div>
      </div>

      {/* ---- 工具清单：真实全名，可复制去对话里用 ---- */}
      {sum && sum.totalTools > 0 && (
        <div className="border-b px-4 py-3">
          <div className="text-xs font-medium">{t('settings.mcpToolsList')}</div>
          <div className="mt-1 space-y-1">
            {Object.entries(status!.kernel!.servers).map(([name, s]) => (
              <div key={name} className="text-xs">
                <span className="text-muted-foreground">{name}</span>
                <span className="ml-1 rounded bg-muted px-1 text-[10px]">{s.expose}</span>
                <span className="ml-2 font-mono">{s.tools.join(', ')}</span>
              </div>
            ))}
          </div>
        </div>
      )}

      <div className="min-h-0 flex-1 overflow-auto">
        <McpConfigEditor />
      </div>
    </div>
  )
}
```
