# 应用智控（App Console）实施计划

> **给执行者：** 本计划按任务逐个执行。每一步都带**可运行的验证命令**，请勿跳步。
> 建议配套技能：`subagent-driven-development`（每任务派一个子 Agent + 任务间复核）或 `executing-plans`。

**Goal:** 在 yfworking 左侧标签栏新增「应用智控」，让用户输入网址或应用路径，由 LLM 生成声明式 `App Spec`，套成自动化控制台，并**仅在进入具体应用时才**把其能力以 `app_*` 工具绑定给 agent。

**Architecture:** 复用项目既有「工作流即工具」模式（`kernel/dyntools.mjs`）——生成**声明式命令表（App Spec）**而非独立程序，由**通用运行器**解释执行；工具可见性沿用 `expose` 三态，默认 `console`（仅当前会话进入指定控制台才可见），绑定状态**落盘** `binding.json` 供内核视图函数每次求值读取（因内核是独立进程）。

**Tech Stack:** Electron（主进程 `electron/*.cjs`）+ React + Vite（渲染层 `src/`）+ 内核 Node ESM（`kernel/*.mjs`）+ `node --test` + 既有 `browser-executor.cjs`。

## Global Constraints

以下为全局硬约束，**每个任务都隐含包含**（值照抄，不得擅改）：

| 约束 | 值 |
|---|---|
| 工具名前缀 | **`app_`**，格式 `app_<slug>_<action>`（同时也是安全兜底关键字） |
| 安全兜底规则 | `kernel/approval-mode.mjs` 的 `classifyTool` 中：`/^app_/` → 返回 **`'appTool'`**（允许档 `bypass`，与 `highRiskBash` 同级）。**不得用 `'write'`**：`write` 的允许档是 `loose`，而默认档正是 `loose`，`2>=2` 会**直接放行**，等于 write 静默执行 |
| 绑定模式 | **严格单开**：`binding.json` 中一个 sessionId 至多一个 appId（值为字符串） |
| `expose.mode` 默认 | **`'console'`** |
| 单应用命令数上限 | **20**（常量 `MAX_COMMANDS_PER_APP = 20`） |
| Spec `params` 形式 | **数组** `[{name, type, required, description}]`，与 `wf.inputs` 同构，直接喂 `deriveInputSchema()` |
| 命令安全分级 | `kind: 'read' \| 'write'`（read→放行，write→需人工确认） |
| 数据根 | `~/.yfworking/apps/`（`~` = `resolveYfwHome()`） |
| 测试框架 | `node --test`（**不是** vitest/jest） |
| 测试文件位置 | 后端 `kernel-tests/app-*.test.mjs`；渲染层 `src/**/*.test.ts` |
| 测试文件首行 | `process.env.PONOS_MOCK_API = '1'`（防真实 API 调用） |
| 测试用例写法 | `import { test } from 'node:test'` + `import assert from 'node:assert/strict'` |
| 单文件测试命令 | `node --test kernel-tests/app-xxx.test.mjs` |
| 全量测试命令 | `npm test` |
| 类型检查 | `npm run typecheck` |
| 提交粒度 | 每个任务结束提交一次（`feat(apps): ...`） |
| 禁止事项 | 不逆向协议；不注入未授权进程；不采集客户个人信息；Spec 内禁止明文密钥；**部署时不覆盖运行时配置** |

```js
// kernel/app-spec.mjs
// 应用智控：Spec 读取 / 校验 / 可见性判定 / 绑定读取
// 纯函数 + 零依赖：内核是独立进程，此处不得依赖 Electron。
import { existsSync, readFileSync } from 'node:fs'
import { join } from 'node:path'

export const EXPOSE_MODES = ['private', 'console', 'public']
export const MAX_COMMANDS_PER_APP = 20
const DEFAULT_EXPOSE_MODE = 'console'

const readJson = (p) => { try { return JSON.parse(readFileSync(p, 'utf-8')) } catch { return null } }

/** 读所有 root 下的 registry.json，合并应用清单 */
export function listApps({ roots = [] } = {}) {
  const out = []
  for (const root of roots) {
    if (!root) continue
    const reg = readJson(join(root, 'registry.json'))
    const items = Array.isArray(reg) ? reg : (Array.isArray(reg?.apps) ? reg.apps : [])
    for (const a of items) if (a && a.id) out.push(a)
  }
  return out
}

/** 读单应用 spec.json（按 root 顺序首个命中优先） */
export function loadSpec({ roots = [], appId } = {}) {
  if (!appId) return null
  for (const root of roots) {
    if (!root) continue
    const p = join(root, appId, 'spec.json')
    if (existsSync(p)) return readJson(p)
  }
  return null
}

/** 读当前会话绑定的应用（严格单开：值是字符串） */
export function getBoundApp({ roots = [], sessionId = null } = {}) {
  if (!sessionId) return null
  for (const root of roots) {
    if (!root) continue
    const binding = readJson(join(root, 'binding.json'))
    const appId = binding?.[sessionId]?.appId
    if (appId) return appId
  }
  return null
}

/**
 * 可见性三态（与 kernel/dyntools.mjs 的 visibilityOf 同构）
 *  private → 永不可见（仅控制台手工执行）
 *  console → 仅当本会话绑定的就是本应用（默认）
 *  public  → 始终可见
 */
export function isAppVisible(spec, { agentId = null, boundApp = null } = {}) {
  if (!spec) return false
  const mode = spec.expose?.mode || DEFAULT_EXPOSE_MODE
  if (!EXPOSE_MODES.includes(mode)) return false   // 未知模式一律不可见（fail-safe）
  if (mode === 'private') return false
  if (mode === 'console') return !!boundApp && boundApp === spec.appId
  return true                                       // public
}

/** Spec 结构校验（纯机械，不含 LLM 判断） */
export function validateSpec(spec) {
  const errors = []
  if (!spec || typeof spec !== 'object' || Array.isArray(spec)) return { ok: false, errors: ['spec 必须是对象'] }
  if (spec.specVersion !== 1) errors.push('specVersion 必须为 1')
  if (!spec.appId) errors.push('缺少 appId')
  if (!spec.name) errors.push('缺少 name')
  if (!['web', 'desktop'].includes(spec.target?.type)) errors.push('target.type 必须为 web 或 desktop')
  if (!Array.isArray(spec.commands)) {
    errors.push('commands 必须是数组')
  } else {
    if (spec.commands.length > MAX_COMMANDS_PER_APP) errors.push(`commands 数量超过上限 ${MAX_COMMANDS_PER_APP}`)
    const seen = new Set()
    for (const c of spec.commands) {
      if (!c || typeof c !== 'object') { errors.push('命令必须是对象'); continue }
      if (!c.action) errors.push('命令缺少 action')
      else if (seen.has(c.action)) errors.push(`action 重复：${c.action}`)
      else seen.add(c.action)
      if (!['read', 'write'].includes(c.kind)) errors.push(`命令 ${c.action || '?'} 的 kind 必须为 read 或 write`)
      if (c.params != null && !Array.isArray(c.params)) errors.push(`命令 ${c.action || '?'} 的 params 必须是数组`)
      if (!Array.isArray(c.steps) || c.steps.length === 0) errors.push(`命令 ${c.action || '?'} 缺少 steps`)
    }
  }
  return { ok: errors.length === 0, errors }
}
```

```js
// electron/app-registry.cjs
// 应用注册表：CRUD + 落盘 + Spec 读写（写前自动备份）
'use strict'
const { existsSync, mkdirSync, readFileSync, writeFileSync, rmSync } = require('node:fs')
const { join } = require('node:path')

const readJson = (p) => { try { return JSON.parse(readFileSync(p, 'utf-8')) } catch { return null } }
const rootOf = (roots) => (Array.isArray(roots) ? roots[0] : roots)
const registryPath = (roots) => join(rootOf(roots), 'registry.json')

function listApps({ roots }) {
  const reg = readJson(registryPath(roots))
  return Array.isArray(reg?.apps) ? reg.apps : []
}

function writeRegistry({ roots, apps }) {
  mkdirSync(rootOf(roots), { recursive: true })
  writeFileSync(registryPath(roots), JSON.stringify({ version: 1, apps }, null, 2), 'utf-8')
}

function upsertApp({ roots, app }) {
  const apps = listApps({ roots })
  const i = apps.findIndex((a) => a.id === app.id)
  if (i >= 0) apps[i] = { ...apps[i], ...app }
  else apps.push(app)
  writeRegistry({ roots, apps })
  mkdirSync(join(rootOf(roots), app.id), { recursive: true })
  return app
}

function removeApp({ roots, appId }) {
  writeRegistry({ roots, apps: listApps({ roots }).filter((a) => a.id !== appId) })
  rmSync(join(rootOf(roots), appId), { recursive: true, force: true })
}

function readSpec({ roots, appId }) {
  return readJson(join(rootOf(roots), appId, 'spec.json'))
}

function writeSpec({ roots, appId, spec }) {
  const dir = join(rootOf(roots), appId)
  mkdirSync(dir, { recursive: true })
  const p = join(dir, 'spec.json')
  // ★ 覆盖前自动备份：绝不静默丢旧版
  if (existsSync(p)) {
    writeFileSync(join(dir, `spec.bak.${Date.now()}.json`), readFileSync(p), 'utf-8')
  }
  writeFileSync(p, JSON.stringify(spec, null, 2), 'utf-8')
  return p
}

module.exports = { listApps, upsertApp, removeApp, readSpec, writeSpec }
```

```js
// electron/app-bindings.cjs
// 应用绑定（严格单开）：sessionId → 至多一个 appId
// 值本身是字符串，物理上无法多开；覆盖写即为原子替换。
'use strict'
const { existsSync, mkdirSync, readFileSync, writeFileSync } = require('node:fs')
const { join } = require('node:path')

const readJson = (p) => { try { return JSON.parse(readFileSync(p, 'utf-8')) } catch { return {} } }
const rootOf = (roots) => (Array.isArray(roots) ? roots[0] : roots)
const bindingPath = (roots) => join(rootOf(roots), 'binding.json')

function readAll(roots) {
  const v = readJson(bindingPath(roots))
  return (v && typeof v === 'object' && !Array.isArray(v)) ? v : {}
}

function writeAll(roots, all) {
  mkdirSync(rootOf(roots), { recursive: true })
  writeFileSync(bindingPath(roots), JSON.stringify(all, null, 2), 'utf-8')
}

function getBoundApp({ roots, sessionId }) {
  if (!sessionId) return null
  return readAll(roots)[sessionId]?.appId ?? null
}

function bindApp({ roots, sessionId, appId }) {
  const all = readAll(roots)
  all[sessionId] = { appId, boundAt: new Date().toISOString() }   // ★ 覆盖 = 严格单开
  writeAll(roots, all)
  return all[sessionId]
}

function unbindApp({ roots, sessionId, appId }) {
  const all = readAll(roots)
  if (all[sessionId]?.appId !== appId) return false   // ★ 防"A 离开"清掉后绑的"B"
  delete all[sessionId]
  writeAll(roots, all)
  return true
}

module.exports = { getBoundApp, bindApp, unbindApp }
```

```ts
import { create } from 'zustand'

export type AppItem = { id: string; name: string; desc?: string; logo?: string; targetType: 'web' | 'desktop'; enabled?: boolean }

export function createAppsStore({ api }: { api: any }) {
  return create<{
    apps: AppItem[]; loading: boolean; error: string | null
    load: () => Promise<void>; upsert: (a: AppItem) => Promise<void>; remove: (id: string) => Promise<void>
  }>((set, get) => ({
    apps: [], loading: false, error: null,
    load: async () => {
      set({ loading: true, error: null })
      try { set({ apps: await api.appList(), loading: false }) }
      catch (e: any) { set({ error: String(e?.message || e), loading: false }) }
    },
    upsert: async (a) => { await api.appUpsert(a); await get().load() },
    remove: async (id) => { await api.appRemove(id); await get().load() },
  }))
}

export const useAppsStore = createAppsStore({ api: (globalThis as any).yfworkingAPI })
```

```js
// electron/app-profiler.cjs
// 应用探测：web（浏览器）/ desktop（process → script → uia 三级降级链）
'use strict'

const SURFACE_ORDER = ['process', 'script', 'uia']   // ★ 越靠前越稳定

/**
 * 判定 driver。pure 判定 + 可注入 probe（便于测试，不真的起进程）。
 */
async function detectDriver({ target, probe } = {}) {
  const type = target?.type
  if (type === 'web') return { driver: 'browser', evidence: { url: target.url } }
  if (type === 'desktop') {
    const probed = probe ? await probe({ exePath: target.exePath }) : { level: 'uia' }
    const level = SURFACE_ORDER.includes(probed?.level) ? probed.level : 'uia'
    return { driver: level, evidence: probed }
  }
  throw new Error(`不支持的 target.type: ${String(type)}`)
}

/** web 探测：打开页面并取快照（供 LLM 生成 Spec 用） */
async function probeWeb({ url, executor, sessionId }) {
  if (!executor) throw new Error('缺少 browserExecutor')
  const nav = await executor.exec(sessionId, 'goto', { url })
  if (!nav?.ok) throw new Error(`导航失败：${nav?.error || '未知'}`)
  const snap = await executor.exec(sessionId, 'snapshot', {})
  return { url, snapshot: snap?.snapshot ?? null, title: snap?.snapshot?.title ?? null }
}

/**
 * desktop 三级探测（降级链：命中即停）
 *  process: 可执行文件是否有可用 CLI（`--help` 有非空输出）
 *  script : 是否有脚本接口（同目录/子目录存在 .lua/.py/.js 扩展目录，或 exe 同级有脚本宿主）
 *  uia    : 兜底（UI 自动化）
 */
async function probeDesktop({ exePath, deps = {} } = {}) {
  const processProbe = deps.processProbe || defaultProcessProbe
  const scriptProbe = deps.scriptProbe || defaultScriptProbe
  const p = await processProbe({ exePath }).catch(() => ({ ok: false }))
  if (p.ok) return { level: 'process', evidence: p }
  const s = await scriptProbe({ exePath }).catch(() => ({ ok: false }))
  if (s.ok) return { level: 'script', evidence: s }
  return { level: 'uia', evidence: { note: '未发现 CLI/脚本接口，降级到 UI 自动化' } }
}

async function defaultProcessProbe({ exePath }) {
  const { execFileSync } = require('node:child_process')
  const out = execFileSync(exePath, ['--help'], { timeout: 5000, encoding: 'utf-8' })
  const text = String(out || '').trim()
  return { ok: text.length > 0, help: text.slice(0, 4000) }
}

async function defaultScriptProbe({ exePath }) {
  const { existsSync, readdirSync } = require('node:fs')
  const { dirname, join } = require('node:path')
  const dir = dirname(exePath)
  if (!existsSync(dir)) return { ok: false }
  const SCRIPT_DIRS = ['scripts', 'extensions', 'plugins', 'lua', 'python']
  const found = SCRIPT_DIRS.filter((d) => existsSync(join(dir, d)))
  return { ok: found.length > 0, dir, scriptDirs: found }
}

module.exports = { detectDriver, probeWeb, probeDesktop, defaultProcessProbe, defaultScriptProbe, SURFACE_ORDER }
```

```js
// electron/app-runner.cjs
// 应用命令执行器：解释执行 App Spec 的 steps
'use strict'
const { appendFileSync, mkdirSync } = require('node:fs')
const { join } = require('node:path')
const registry = require('./app-registry.cjs')

/** 替换 ${name} 占位符（未提供则替换为空串） */
function interpolate(input, args = {}) {
  if (typeof input !== 'string') return input
  return input.replace(/\$\{(\w+)\}/g, (_m, k) => (args[k] == null ? '' : String(args[k])))
}

/** 校验必填参数 */
function checkRequired(params = [], args = {}) {
  const errors = []
  for (const p of params || []) {
    if (p?.required && (args[p.name] == null || args[p.name] === '')) errors.push(`缺少必填参数：${p.name}`)
  }
  return { ok: errors.length === 0, errors }
}

function appendHistory({ roots, appId, entry }) {
  const dir = join(roots[0], appId, 'history')
  mkdirSync(dir, { recursive: true })
  const day = new Date().toISOString().slice(0, 10)
  appendFileSync(join(dir, `${day}.jsonl`), JSON.stringify(entry) + '\n', 'utf-8')
}

async function runCommand({ roots, appId, action, args = {}, executor, sessionId }) {
  const startedAt = Date.now()
  const spec = registry.readSpec({ roots, appId })
  const cmd = spec?.commands?.find((c) => c.action === action)
  const base = { appId, action, args, kind: cmd?.kind ?? 'unknown', at: new Date().toISOString() }

  const fail = (error) => {
    const r = { ok: false, data: null, error, kind: base.kind, durationMs: Date.now() - startedAt }
    appendHistory({ roots, appId, entry: { ...base, ok: false, error } })
    return r
  }

  if (!cmd) return fail(`未找到命令：${action}`)

  const req = checkRequired(cmd.params, args)
  if (!req.ok) return fail(req.errors.join('；'))

  try {
    let saved = null
    for (const step of cmd.steps || []) {
      const params = { ...(step.url ? { url: interpolate(step.url, args) } : {}),
                       ...(step.selector ? { selector: step.selector } : {}),
                       ...(step.value != null ? { value: interpolate(step.value, args) } : {}),
                       ...(step.ms != null ? { ms: step.ms } : {}),
                       ...(step.expression ? { expression: interpolate(step.expression, args) } : {}) }
      const res = await executor.exec(sessionId, step.act, params)
      if (!res?.ok) return fail(`步骤 ${step.act} 失败：${res?.error || '未知错误'}`)
      if (step.save) saved = step.act === 'snapshot' ? (res.snapshot?.text ?? res.snapshot) : res
    }
    const r = { ok: true, data: saved, error: null, kind: cmd.kind, durationMs: Date.now() - startedAt }
    appendHistory({ roots, appId, entry: { ...base, ok: true, durationMs: r.durationMs } })
    return r
  } catch (e) {
    return fail(String(e?.message || e))
  }
}

module.exports = { runCommand, interpolate, checkRequired, appendHistory }
```

```js
// electron/app-runner-desktop.cjs
// desktop 目标的三级执行：process / script / uia
// deps 可注入，便于单测（不真的拉起进程）
'use strict'
const { execFile } = require('node:child_process')
const { promisify } = require('node:util')
const execFileAsync = promisify(execFile)
const { interpolate, checkRequired } = require('./app-runner.cjs')

const CLI_TIMEOUT = 30000

function buildArgv(argv = [], args = {}) { return argv.map((a) => interpolate(a, args)) }

async function runCli({ exePath, argv, timeout = CLI_TIMEOUT }) {
  const { stdout, stderr } = await execFileAsync(exePath, argv, { timeout, encoding: 'utf-8', windowsHide: true })
  return { ok: true, stdout, stderr }
}

async function runScript({ lang, file, code, exePath }) {
  // lang → 宿主命令的映射在实现时按目标应用实际接口填（aseprite 用 -b --script）
  const HOST = { lua: exePath, python: 'python', node: process.execPath }
  const host = HOST[lang]
  if (!host) return { ok: false, error: `不支持的脚本语言：${lang}` }
  const argv = file ? [file] : ['-e', code]
  const { stdout } = await execFileAsync(host, argv, { timeout: CLI_TIMEOUT, encoding: 'utf-8', windowsHide: true })
  return { ok: true, stdout }
}

async function runUia({ act, selector, value, key }) {
  // UI 自动化兜底：实现时接 Windows UIA / SendKeys 能力
  return { ok: false, error: 'UI 自动化后端尚未接入（uia 兜底路径）' }
}

async function desktopRunner({ appId, action, args = {}, spec, deps = {} }) {
  const runCliFn = deps.runCli || runCli
  const runScriptFn = deps.runScript || runScript
  const runUiaFn = deps.runUia || runUia
  const startedAt = Date.now()

  const driver = spec?.driver
  if (!['process', 'script', 'uia'].includes(driver)) {
    return { ok: false, data: null, error: `不支持的 driver：${String(driver)}`, kind: 'unknown', durationMs: 0 }
  }
  const cmd = spec?.commands?.find((c) => c.action === action)
  if (!cmd) return { ok: false, data: null, error: `未找到命令：${action}`, kind: 'unknown', durationMs: 0 }

  const req = checkRequired(cmd.params, args)
  if (!req.ok) return { ok: false, data: null, error: req.errors.join('；'), kind: cmd.kind, durationMs: Date.now() - startedAt }

  try {
    let saved = null
    for (const step of cmd.steps || []) {
      if (driver === 'process' && step.act === 'cli') {
        const res = await runCliFn({ exePath: spec.target?.exePath, argv: buildArgv(step.argv, args) })
        if (!res.ok) throw new Error(res.error || 'CLI 执行失败')
        if (step.save) saved = res.stdout
      } else if (driver === 'script' && step.act === 'script') {
        const res = await runScriptFn({ lang: step.lang, file: step.file, code: interpolate(step.code, args), exePath: spec.target?.exePath })
        if (!res.ok) throw new Error(res.error || '脚本执行失败')
        if (step.save) saved = res.stdout
      } else if (driver === 'uia') {
        const res = await runUiaFn({ ...step, value: interpolate(step.value, args) })
        if (!res.ok) throw new Error(res.error || 'UI 自动化失败')
        if (step.save) saved = res
      } else {
        throw new Error(`driver=${driver} 不支持步骤 ${step.act}`)
      }
    }
    return { ok: true, data: saved, error: null, kind: cmd.kind, durationMs: Date.now() - startedAt }
  } catch (e) {
    return { ok: false, data: null, error: String(e?.message || e), kind: cmd.kind, durationMs: Date.now() - startedAt }
  }
}

module.exports = { desktopRunner, buildArgv, runCli, runScript, runUia }
```

```tsx
export function AppConsole({ appId, sessionId, onBack }: { appId: string; sessionId: string; onBack: () => void }) {
  const [spec, setSpec] = useState<Spec | null>(null)
  const [checking, setChecking] = useState(true)

  useEffect(() => {
    let alive = true
    ;(async () => {
      const s = await window.yfworkingAPI.appReadSpec(appId)
      if (!alive) return
      setSpec(s)
      const r = await window.yfworkingAPI.appCheck(appId)      // Task 2.6 提供

      if (r.status === 'healthy' || r.status === 'drifted') {
        await window.yfworkingAPI.appEnterConsole({ sessionId, appId })
        if (alive) setBound(true)
      }
    })()
    return () => {
      alive = false
      // ★ 离开即解绑：不 await（卸载中），失败也不影响 UI
      void window.yfworkingAPI.appLeaveConsole({ sessionId, appId })
      setBound(false)
    }
  }, [appId, sessionId])

  if (checking) return <div className="app-console__checking">正在校验…</div>
  if (check && check.status === 'broken') {
    return (
      <div className="app-console__broken">
        <p>该应用已失效，需重建（未自动修改你的 Spec）</p>
        <ul>{check.issues.map((i, k) => <li key={k}>{i}</li>)}</ul>
        <button onClick={onBack}>返回</button>
      </div>
    )
  }
  return (
    <div className="app-console">
      <header className="app-console__head">
        <button onClick={onBack}>← 返回</button>
        <h2>{spec?.name}</h2>
        {bound && <span className="app-console__badge" title="该应用的能力已接给当前会话的 AI">AI 已接入</span>}

  )
}
```

```js
// electron/app-validator.cjs
// 应用有效性校验：完整性 / 可达性 / 保真性（抽样 read 试跑）
'use strict'
const { createRequire } = require('node:module')
const registry = require('./app-registry.cjs')

async function checkApp({ roots, appId, deps = {} }) {
  const readSpecFn = deps.readSpec || (() => registry.readSpec({ roots, appId }))
  const probeReachableFn = deps.probeReachable || defaultProbeReachable
  const runCommandFn = deps.runCommand

  const issues = []

  // ① 完整性
  const spec = readSpecFn({ roots, appId })
  const { validateSpec } = await import('../kernel/app-spec.mjs')
  const v = validateSpec(spec)
  if (!v.ok) return { status: 'broken', issues: v.errors }

  // ② 可达性
  const reach = await probeReachableFn({ target: spec.target }).catch((e) => ({ ok: false, error: String(e?.message || e) }))
  if (!reach?.ok) return { status: 'broken', issues: [`目标不可达：${reach?.error || '未知'}`] }

  // ③ 保真性：只抽查 read（write 绝不试跑）
  const reads = (spec.commands || []).filter((c) => c.kind === 'read')
  for (const c of reads.slice(0, 2)) {
    const r = await runCommandFn?.({ roots, appId, action: c.action, args: {}, sessionId: '__check__' })
    if (r && !r.ok) issues.push(`命令 ${c.action} 试跑失败：${r.error}`)
  }
  return { status: issues.length ? 'drifted' : 'healthy', issues }
}

async function defaultProbeReachable({ target }) {
  if (target?.type === 'web') {
    try {
      const res = await fetch(target.url, { method: 'HEAD' })
      return { ok: res.ok || res.status < 500, status: res.status }
    } catch (e) { return { ok: false, error: String(e?.message || e) } }
  }
  const { existsSync } = require('node:fs')
  return { ok: existsSync(target?.exePath || ''), error: existsSync(target?.exePath || '') ? undefined : '程序路径不存在' }
}

module.exports = { checkApp, defaultProbeReachable }
```

```js
// electron/app-generate.cjs
// LLM 生成 App Spec：buildPrompt（纯）→ callLlm → extractSpec（纯）→ validateSpec → 回喂修正
'use strict'

const MAX_ROUNDS = 3

/** 从模型文本中抠出 Spec JSON（容忍 markdown 代码块与前后噪声） */
function extractSpec(text) {
  if (!text || typeof text !== 'string') return null
  const fence = text.match(/```(?:json)?\s*([\s\S]*?)```/i)
  const candidate = fence ? fence[1] : text
  try { return JSON.parse(candidate.trim()) } catch { /* 继续尝试 */ }
  const first = candidate.indexOf('{')
  const last = candidate.lastIndexOf('}')
  if (first >= 0 && last > first) {
    try { return JSON.parse(candidate.slice(first, last + 1)) } catch { return null }
  }
  return null
}

/** 构造提示词（契约写死在 system 里，避免模型自由发挥） */
function buildPrompt({ target, probeMaterial }) {
  const system = [
    '你是"应用智控"的 App Spec 生成器。只输出一个 JSON 对象，不要解释。',
    'Spec 结构约束（必须严格遵守）：',
    '1) specVersion 必须为 1；必须含 appId、name、desc。',
    '2) target: { type: "web"|"desktop", url? , exePath? }。',
    '3) expose: { mode: "console" }（默认，不要改成 public）。',
    '4) commands 为数组，每项含：action（英文驼峰、唯一）、title（中文）、kind（只能是 "read" 或 "write"）、',
    '   params（必须是数组，每项 { name, type, required, description }）、steps（非空数组）、',
    '   returns（可选 { type: "text"|"table"|"json"|"file", from: "<save 名>" }）。',
    '5) kind 判定规则：只读取/查询/导出 → "read"；提交/修改/删除/下发/发送 → "write"。',
    '6) steps 的 act 只能取 web 驱动动作：[goto, click, type, select, scroll, hover, js, wait, snapshot]；',
    '   desktop 驱动动作：[cli, script, focus, key]。',
    '7) 不要编造不存在的接口；无法确定的选择器请省略该命令。',
    '8) 严禁在 Spec 中出现任何密钥、口令、token。',
  ].join('\n')

  const user = [
    `目标：${JSON.stringify(target)}`,
    '探测素材（可能含页面结构/表单/表格/帮助输出）：',
    JSON.stringify(probeMaterial ?? {}).slice(0, 20000),
    '请产出完整 App Spec JSON。',
  ].join('\n\n')

  return { system, user }
}

/** 生成主流程：最多 MAX_ROUNDS 轮，每轮把校验错误回喂 */
async function generateSpec({ target, probe, callLlm, maxRounds = MAX_ROUNDS }) {
  const { validateSpec } = await import('../kernel/app-spec.mjs')
  const probeMaterial = await probe({ target })
  let lastIssues = []

  for (let round = 1; round <= maxRounds; round++) {
    const { system, user } = buildPrompt({
      target,
      probeMaterial: round === 1 ? probeMaterial : { ...probeMaterial, previousErrors: lastIssues },
    })
    const text = await callLlm({
      system,
      user: round === 1 ? user : `${user}\n\n上一轮输出不合法，错误如下，请仅输出修正后的完整 JSON：\n${lastIssues.join('\n')}`,
    })
    const spec = extractSpec(text)
    if (spec) {
      const v = validateSpec(spec)
      if (v.ok) return { ok: true, spec, rounds: round, issues: [] }
      lastIssues = v.errors
    } else {
      lastIssues = ['输出不是合法 JSON']
    }
  }
  return { ok: false, spec: null, rounds: maxRounds, issues: lastIssues }
}

/** 真实 LLM 调用：复用内核既有 provider（实现前先 Read kernel/provider.mjs 确认导出名） */
async function defaultCallLlm({ system, user }) {
  const { callProvider } = await import('../kernel/provider.mjs')
  return callProvider({ system, user, maxTokens: 8000 })
}

module.exports = { extractSpec, buildPrompt, generateSpec, defaultCallLlm, MAX_ROUNDS }
```

```js
/**
 * 实跑验证：只试跑 read 命令（write 绝不试跑——那是用户的真实数据）
 * 无 read 命令时无法验证 → 视为不通过，要求 LLM 补一条查询类命令
 */
async function verifySpec({ spec, runCommand, sessionId = '__verify__' }) {
  const reads = (spec?.commands || []).filter((c) => c.kind === 'read')
  if (reads.length === 0) {
    return { ok: false, tried: [], failures: ['Spec 中没有 read 命令，无法实跑验证，请至少提供一条查询类命令'] }
  }
  const tried = []
  const failures = []
  for (const c of reads.slice(0, 2)) {
    tried.push(c.action)
    const r = await runCommand({ appId: spec.appId, action: c.action, args: {}, sessionId, spec })
    if (!r?.ok) failures.push(`命令 ${c.action}：${r?.error || '未知错误'}`)
  }
  return { ok: failures.length === 0, tried, failures }
}
```

```js
function listBackups({ roots, appId }) {
  const dir = join(rootOf(roots), appId)
  if (!existsSync(dir)) return []
  return readdirSync(dir)
    .filter((f) => /^spec\.bak\.\d+\.json$/.test(f))

function restoreSpec({ roots, appId, backupName }) {
  if (!/^spec\.bak\.\d+\.json$/.test(backupName || '')) throw new Error('非法备份名')   // 防路径穿越

  writeSpec({ roots, appId, spec: content })   // 复用：恢复前也会备份当前版本
```

```js
/**
 * 漂移修复：只重生成失败的命令，整体 Spec 合法性校验通过才写盘
 * 写盘走 registry.writeSpec → 自动备份旧版（可回滚）
 */
async function repairApp({ roots, appId, deps = {} }) {
  const readSpecFn = deps.readSpec || (() => registry.readSpec({ roots, appId }))
  const findFailuresFn = deps.findFailures || (async () => (await checkApp({ roots, appId, deps })).issues.map((s) => s.match(/命令 (\w+)/)?.[1]).filter(Boolean))
  const regenerateFn = deps.regenerateCommand
  const writeSpecFn = deps.writeSpec || (({ spec }) => registry.writeSpec({ roots, appId, spec }))

  const spec = readSpecFn({ roots, appId })
  if (!spec) return { ok: false, repaired: [], error: 'Spec 不存在' }

  const failing = await findFailuresFn({ roots, appId, spec })
  if (!failing.length) return { ok: true, repaired: [], backup: null }

  const next = JSON.parse(JSON.stringify(spec))
  const repaired = []
  for (const action of failing) {
    const i = next.commands.findIndex((c) => c.action === action)
    if (i < 0) continue
    const fixed = await regenerateFn({ spec, command: next.commands[i], action })
    if (fixed) { next.commands[i] = fixed; repaired.push(action) }
  }
  if (!repaired.length) return { ok: false, repaired: [], error: '未能生成有效修复' }

  const { validateSpec } = await import('../kernel/app-spec.mjs')
  const v = validateSpec(next)
  if (!v.ok) return { ok: false, repaired: [], error: `修复结果不合法，已放弃：${v.errors.join('；')}` }   // ★ 宁可不修，不可改坏

  const before = registry.listBackups({ roots, appId }).length
  writeSpecFn({ roots, appId, spec: next })
  const backup = registry.listBackups({ roots, appId }).slice(before)[0] || null
  return { ok: true, repaired, backup }   // ★ 必须回报用户
}
```

```js
// kernel/app-tools.mjs
// 「应用即工具」：与 kernel/dyntools.mjs 的 buildWorkflowTools 完全同构
// 默认 console 模式 → 只有进入控制台的会话才看得到这些工具
import { deriveInputSchema, slugToToolName, shortHash, LIMIT_DEFAULT } from './dyntools.mjs'
import { listApps, loadSpec, isAppVisible, getBoundApp, MAX_COMMANDS_PER_APP } from './app-spec.mjs'

const APP_PREFIX = 'app_'

export function buildAppTools({ roots = [], agentId = null, sessionId = null, publicLimit, runner } = {}) {
  const tools = {}
  const conflicts = []
  const boundApp = getBoundApp({ roots, sessionId })     // ★ 每次求值读 binding.json

  for (const app of listApps({ roots })) {
    if (app.enabled === false) continue
    const spec = loadSpec({ roots, appId: app.id })
    if (!isAppVisible(spec, { agentId, boundApp })) continue   // ★ 三态可见性（严格单开）

    const slug = slugToToolName(spec.name || app.id)
    for (const cmd of (spec.commands || []).slice(0, MAX_COMMANDS_PER_APP)) {
      const preferred = `${APP_PREFIX}${slug}_${cmd.action}`
      let name = preferred
      if (Object.hasOwn(tools, name)) {                  // 同 dyntools：不静默覆盖
        const alt = `${preferred}_${shortHash(app.id + cmd.action)}`
        name = alt
        for (let i = 2; Object.hasOwn(tools, name); i++) name = `${alt}${i}`
        conflicts.push({ app: app.id, preferred, resolved: name })
      }
      const isWrite = cmd.kind === 'write'
      tools[name] = {
        description: `[${spec.name || app.id}] ${cmd.title || cmd.action}${isWrite ? '（写操作，需确认）' : ''}`,
        input_schema: deriveInputSchema(cmd.params),      // ★ params 为数组，零适配
        concurrencySafe: !isWrite,
        run: async (args = {}) => {
          try {
            const r = await (runner || defaultRunner)({ appId: app.id, action: cmd.action, args, sessionId })
            return { content: JSON.stringify(r), isError: !r?.ok }
          } catch (e) {
            return { content: JSON.stringify({ ok: false, error: String(e?.message || e) }), isError: true }
          }
        },
      }
    }
  }

  // 公开数量截断（沿用 dyntools 的 LIMIT_DEFAULT 语义）
  const limit = Number.isInteger(publicLimit) ? publicLimit : LIMIT_DEFAULT
  const names = Object.keys(tools)
  if (names.length > limit) {
    const kept = {}
    for (const n of names.slice(0, limit)) kept[n] = tools[n]
    Object.defineProperty(kept, 'nameConflicts', { enumerable: false, value: conflicts })
    return kept
  }
  Object.defineProperty(tools, 'nameConflicts', { enumerable: false, value: conflicts })
  return tools
}

/** 默认执行器：内核进程通过 HTTP/IPC 让 Electron 侧跑（实现时接既有 bridge 通道） */
async function defaultRunner({ appId, action, args, sessionId }) {
  throw new Error('未注入 runner：请由 kernel/cli.mjs 注入 app:run 转发实现')
}

export { APP_PREFIX }
```

> **runner 注入方式**：内核是独立进程，无法直接 require Electron 模块。
> 沿用既有做法（如 `browser:exec` 走 bridge WS），在 `kernel/cli.mjs` 里注入一个
> 通过 bridge 请求 Electron 侧 `app:run` 的函数。**实现前先 `Read` `kernel/cli.mjs` 中
> 现有的 bridge 调用封装**（与 `browser-executor` 同源），直接复用，不要另造。

## 真机验收轮（2026-09-13 下午，独立一轮）

### 触发原因（真实反馈，改变了生成链路的形态）

用户实测：给 `https://www.kimi.com/?chat_enter_method=new_chat` 生成命令时直接失败——

> 导航失败：目标域名不在白名单（默认 \*.gov.cn/localhost），已拒绝导航

用户判断"建立 CLI 为何需要内置浏览器？这种模式不适合，最好需要用户无感，后台 LLM 获取，
前端 UI 显示进度动画用户感知即可"。该判断成立，且暴露了架构上的概念混淆。

### 结论一：取素材与自动化浏览是两件事（已改）

| 事 | 安全边界 | 现状 |
| --- | --- | --- |
| agent **自主浏览**（点按钮/填表单/发请求） | 必须收紧：默认白名单 `*.gov.cn/localhost/搜索引擎/企业查询/邮箱` | **不变** |
| **生成命令**时取一份页面素材给模型看 | 用户自己填的网址＝显式授权，等价于用户亲手打开该页 | 改为**主进程后台 HTTP 抓取**（`electron/app-http-probe.cjs`，无窗口、不经白名单） |

- 浏览器探测**降级为可选增强**：仅当「静态素材不足 **且** 该域名本就在白名单内」时才开浏览器取真实 DOM。
  顺序上先判白名单、后授权——反过来会让 `isWhitelisted` 恒真，导致每个站点都去开浏览器（违背"无感"）。
- **执行侧**同样需要授权：生成 / 试跑 / 执行（含 AI 工具调用）都会经 `BrowserExecutor` 导航，
  真机验收发现试跑仍被拦（`目标域名不在白名单…已拒绝导航: https://www.kimi.com/mykimi`），
  于是补 `authorizeAppTarget()`：把**用户保存过的应用 target 主机名**加入运行时白名单
  （进程内有效、**不落盘**、**精确主机名**，不扩散到子域/同域其它主机）。
- 取不到素材**不再中止生成**：降级为"靠公开知识保守推断"，并在界面**明说**"未取得页面素材、
  命令可能不准确、请逐条核对"，同时给"仍要保存（未验证）"的显式出口（否则用户被卡死在对话框）。

### 结论二：真机暴露了三处"假执行器掩盖的真实缺陷"（已修）

三处的共同根因：测试里的假执行器都额外带了 `text` 字段，而**真实快照**
（`electron/browser-common.cjs` 的 `buildSnapshot`）**没有顶层 text/url/title**，
页级字段在 `page` 下。

| # | 位置 | 症状 | 修法 |
| --- | --- | --- | --- |
| ① | `app-runner.cjs` save 语义 | `res.snapshot.text` 为 undefined → 退回整坨快照对象（1KB+ JSON），查询命令"成功但没结果" | 新增 `snapshotToText()`（`app-util.cjs`）统一归一 + 4000 字上限 |
| ② | `app-profiler.probeWeb` | `snapshot.title` 恒 null → 探测结果无标题 | 改读 `snapshot.page.title`（扁平口径保留兜底） |
| ③ | `app-ipc.profiledSnapshot` | url/title 恒空 | 同上 |

另两处真机发现：
- 模型写出 `{{orderNo}}` 而实现只认 `${orderNo}` → **参数化命令静默失效**
  （且因"需参数被跳过试跑"而查不出来）。`interpolate` 现同时认两种写法，提示词也已写明。
- 生成素材此前**不含 `info`**（页面正文 label/value）→ 模型只知道"能点什么"、不知道"页面里有什么"。已补入。
